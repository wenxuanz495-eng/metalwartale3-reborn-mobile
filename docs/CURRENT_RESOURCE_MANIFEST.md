## 使用规则

1. 资源变更时：更新黄金清单哈希 + 在本清单登记批准哈希（双重登记，两处一致=已批准）。
2. `prepare_build_runtime.bat` 对本清单登记的资源优先使用本清单哈希校验；未登记资源使用黄金清单。
3. 任一清单缺失、哈希不匹配或资源不存在都会停止准备阶段。
