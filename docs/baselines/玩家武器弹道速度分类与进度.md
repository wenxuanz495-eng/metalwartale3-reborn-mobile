# 玩家武器弹道速度分类与进度

> 本文件是持续维护的速度调整清单。每完成一批武器调整后，必须重新运行 `pwsh -NoProfile -File .\tools\update_player_weapon_speed_catalog.ps1` 更新状态。

> 维护警告：不要只修改 `bulletSpeed`。遇到弹道密度、飞行中加速或新旧版本手感不一致时，必须同时检查 `bulletMaxV`、`bulletMaxVa`、`bulletLife`、`attackGap` 和相关追踪参数。详细规则见 [AI武器弹速维护提示](../AI武器弹速维护提示.md)。
