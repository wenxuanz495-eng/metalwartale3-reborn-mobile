# 2.5 玩家武器弹速恢复基线

本基线只处理玩家主武器和副武器，不包含敌人或 Boss 武器。

## 对应规则

- `arms id` 是武器家族 ID，也是首要对应键。
- `armsLevel` 在家族内的顺序是升级阶段号。
- 武器名称只用于人工复核，不作为唯一对应键，因为后续版本存在改名。
- 当前版本同一家族新增的升级阶段不在本轮修改范围内。
- 本轮恢复所有 2.5 中存在显式 `bulletSpeed` 的玩家武器阶段；家族内有多档速度时按阶段恢复。
- 2.5 没有显式 `bulletSpeed` 的激光类家族保持现状，不补写速度值。

完整名单见 `2.5玩家武器弹速基线名单.csv`。名单记录家族 ID、阶段号、2.5 名称、当前名称、修改前后弹速和当前家族总阶段数。

## 2.5 中按阶段恢复的非统一家族

- 主武器 `shotgun`：按阶段恢复为 `25/25/25/20`。
- 副武器 `chipped`：按阶段恢复为 `35/35/35/35/25`。
- 主武器 `induction_1`、`microwave_1` 以及副武器 `laser`、`hotline`：2.5 中没有显式 `bulletSpeed`。

## 重复执行

在仓库根目录运行：

```powershell
pwsh -NoProfile -File .\tools\restore_25_weapon_bullet_speeds.ps1
```
