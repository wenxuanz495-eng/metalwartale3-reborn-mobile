# 3.4 新增玩家武器弹速趋同

## 范围

本名单只包含同时满足以下条件的玩家武器形态：

- 原版 3.4 已存在。
- 当前代码库 `D:\superalloy\metalwartale3-reborn.git` 已存在。
- 原版 2.5 中相同家族 ID 和阶段不存在。
- 不包含敌人或 Boss 武器。

家族 ID 是首要对应键，家族内 `armsLevel` 顺序作为阶段号，中文名称只用于人工复核。

## 统计

- 共找到 33 个符合范围的形态：主武器 26 个，副武器 7 个。
- 18 个形态的弹速已经与 3.4 一致，无需修改。
- 15 个形态需要修改，全部属于主武器。
- 副武器本轮没有需要修改的项目。
- `flyLaser` 在 3.4 和当前版本中都没有显式 `bulletSpeed`，保持不动。

## 建议批次

1. `arc` / 斯巴达：`150 -> 30`。单独验证普通弹丸的速度、射程和命中表现。
2. 十二星座家族：12 个家族全部恢复为 `35`。当前值按家族分布在 `60/80/100`。
3. `magneticTrack`：恐惧镰刀、恐惧先驱从 `85` 恢复为 `40`。当前家族还有 3 个晚于 3.4 的新增阶段，本批只处理 3.4 已有的前两阶段。

完整逐项数据见 `3.4新增玩家武器弹速对照名单.csv`。
