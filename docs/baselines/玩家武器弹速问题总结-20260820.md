# 玩家武器弹速问题总结（2026-08-20）

## 问题现象

部分武器的 `bulletSpeed` 虽然已经恢复到 2.5/3.4 的数值，但实战视觉仍然与老版本不同，表现为：

- 子弹发射后逐渐加速。
- 连续子弹之间的距离被拉大，弹道密度降低。
- 看起来像是速度恢复了，但实际飞行中仍然很快。

## 根因

子弹速度由多个字段共同决定，而不是只有 `bulletSpeed`：

```text
初始速度：bulletSpeed
最高速度：bulletMaxV
每逻辑帧加速度：bulletMaxVa
```

运行时逻辑会持续执行：

```as3
v0 += a0;
if (v0 > vmax)
{
    v0 = vmax;
}
```

因此，如果只把 `bulletSpeed` 降低，但保留非零 `bulletMaxVa`，子弹仍会在飞行中重新加速。

## 本次发现并修正的武器

### 感应炮 `induction`

形态：青龙、白虎、朱雀、玄武。

2.5/3.4 基线：

```text
bulletSpeed = 2
bulletMaxV = 30
bulletMaxVa = 0
followB = 3
```

当前版本曾经是：

```text
bulletSpeed = 2
bulletMaxV = 40
bulletMaxVa = 1
```

这会让子弹约 1.27 秒后加速到 40，造成弹链逐渐拉开。现在已恢复为老版本运动参数。

### 微波炮 `microwave`

形态：回音、末日回响、潮信、最后轻语、浩劫呼唤。

2.5/3.4 基线：

```text
bulletSpeed = 35
bulletMaxV = 35
bulletMaxVa = 0
```

当前版本曾经保留：

```text
bulletSpeed = 35
bulletMaxV = 50
bulletMaxVa = 10
```

子弹约两帧就会达到 50，导致仅看初速度无法发现问题。现在已恢复为老版本运动参数。

### 离子加农炮 `ioncanon`：无畏

这是当前版本独有的成长型、穿透主武器，不属于 2.5/3.4 基线武器。

本次按“其余武器速度除以 2.5”的规则处理：

```text
bulletSpeed = 20
bulletMaxV = 20
bulletMaxVa = 4
```

由于最高速度已经等于初速度，实际不会超过 20。它的素材标签是 `lizijianongpao_lv1`。
