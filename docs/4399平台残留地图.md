> 定位：客户端（`decompiled\`）里原 4399 平台代码的**集中地图**——接手或清理平台相关代码前先读本文，避免误改被离线化链路依赖的部分。

**改这些常量不会让游戏离线功能变化**——离线版走本地服务端；它们只在平台残留代码路径被触达时使用。

## 六、客户端网络约定的好消息

客户端**没有**写死的 IP 以外的本地地址、**没有**写死端口、**没有**文件系统绝对路径。全部本地 API 走相对路径（`api/game-save`、`/api/bgm/*`、`api/client-log` 等），依赖"game.swf 被伺服在站点根路径"的约定（见 `docs\runtime\BAT_RUNTIME.md` 端口与地址约定节）。
