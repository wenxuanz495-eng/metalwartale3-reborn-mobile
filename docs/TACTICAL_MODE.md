# 战术实验与 Roguelike 模式

## 设计目标

原游戏的主要操作是移动、跳跃、技能和持续射击，后期容易变成纯数值碾压。新模式应让玩家根据敌人、环境和武器状态调整打法，形成可观察、可学习的高 DPS 操作空间。

第一版应独立于主线，避免一次性重做所有旧武器和敌人。

## 推荐系统结构

### 基础伤害

保留接近原系统的四大类：

- 动能
- 爆炸
- 能量
- 时空

其中时空是稀有类型，但不能无视全部抗性。它应以高穿透、低射速、高代价体现价值。

### 附加效果

- 热能：累积热量或灼烧。
- EMP：累积失衡值，触发短暂瘫痪或技能中断。
- 机械震荡：擅长范围清怪、破坏部件或降低装甲。
- 穿透：忽略一定比例护甲或穿过目标。

一件武器可拥有一个基础伤害类型和一至两个附加效果。例如：

- “深渊”：动能＋机械震荡＋穿透。
- “浩劫呼唤”：能量＋EMP。
- “赤红烈焰”：能量＋热能。
- “黑洞”：时空＋穿透，附带高能耗和低射速。

## 武器框架

### 普通框架

无明显增益和减益，是稳定基准。

### 超轻框架

- 移速、转向、跳跃和弹药/能量储备提高。
- 对重甲目标效率降低。

### 重型框架

- 单发伤害、弹速和穿透提高。
- 后坐力、噪音和热量提高。
- 降低移速、跳跃高度和空中转向。

### 连续框架

- 射速和持续 DPS 提高。
- 快速积累过热。
- 长时间压枪时精度和效率下降。

### 狙击框架

- 单发、暴击和弱点倍率提高。
- 射速、弹药量和容错降低。

## 过热

```text
当前热量 += 单发热量
当前热量 -= 散热速度 × 时间

0%～79%：正常
80%～99%：射速和精度逐步降低
100%：强制散热，短时间不能射击
```

散热插件可以降低单发热量、提高散热速度或缩短强制散热时间。

## EMP与控制

EMP采用积累值，不使用无条件永久瘫痪：

- 普通敌人：满值后瘫痪 2～4 秒。
- 精英敌人：满值后瘫痪约 1 秒。
- Boss：中断当前技能，并获得短时间 EMP 抗性。

这样既保留控制玩法，也不会跳过 Boss 机制。

## 敌人抗性

第一版只给精英和 Boss 配置两项明显特征：

- 一个优势抗性；
- 一个弱点。

抗性必须通过颜色、受击文字、图标或图鉴说明反馈给玩家，不能只在后台改变伤害数字。

## 环境规则

候选环境：

- 稀薄大气：机械波效果下降、能耗提高。
- 低重力：跳跃和击退增强，重型武器惯性更明显。
- 高温：散热变慢。
- 电磁风暴：EMP效果增强，但能量武器稳定性下降。
- 浮空平台：强调空中移动和击退控制。

不建议让某类武器在环境中完全不可用。应保留低效率使用和插件补偿的可能。

## Roguelike 局内循环

```text
选择初始战车/武器
  → 进入带环境词条的关卡
  → 从风险、强化、资源三类奖励中选择
  → 形成武器框架与附加效果组合
  → 精英战
  → Boss战
  → 结算长期资源
```

奖励应包含取舍，例如：

- 射速提高 25%，单发热量提高 20%。
- 低于 30% 耐久时穿透提高。
- EMP积累翻倍，但直接伤害降低。
- 空中伤害提高，地面移速降低。

## 实施阶段

1. 用少量指定武器实现框架参数修正。
2. 加入热量槽和两个过热阶段。
3. 给少量敌人增加弱点/抗性。
4. 在一个独立副本加入随机环境。
5. 完成后再决定是否扩展到主线和全部装备。
