# 2.5 公共受击特效与小黄豆、火神炮共用关系

日期：2026-09-04

## 结论

2.5 版本中，小黄豆家族和火神炮家族使用同一组公共受击特效，并不是小黄豆专用特效。

两者的配置调用均为：

```text
sub/motion_hit_effect
```

运行时会根据 `BulletBody.hitImgLabel` 的处理逻辑，随机补充后缀，实际调用以下四种表现之一：

```text
sub/motion_hit_effect_1
sub/motion_hit_effect_2
sub/motion_hit_effect_3
sub/motion_hit_effect_4
```

## 已核对的武器家族

### 小黄豆家族

```text
arms id="soya"
hitImgLabel = sub/motion_hit_effect
```

### 火神炮家族

```text
arms id="fireFairy"
hitImgLabel = sub/motion_hit_effect
```

这说明二者共用 `sub` 公共资源组中的同一套命中特效。不同的视觉表现来自 `_1` 至 `_4` 四个静态特效变体，而不是来自不同武器各自独立的受击动画。

## 与仓库旧版调用的区别

当前仓库小黄豆在覆盖 2.5 特效以前使用的是：

```text
bullet/yellow_motion
```

这是一套位于 `bullet.swf` 中的旧版黄色受击特效，与 2.5 的：

```text
sub/motion_hit_effect_1～4
```

不是同一组资源。

因此应区分两个目标：

| 目标 | 正确调用 | 含义 |
|---|---|---|
| 恢复 GitHub 仓库小黄豆覆盖前的状态 | `bullet/yellow_motion` | 仓库旧版调用 |
| 恢复 2.5 版本视觉效果 | `sub/motion_hit_effect` | 2.5 公共受击特效，随机使用 `_1～4` |

## 对后续导入工作的参考意义

以后检查或导入武器受击特效时，不能只按武器名称判断资源归属。应先检查配置中的 `hitImgLabel`，再确认 `father` 与资源 SWF：

```text
配置 hitImgLabel
→ father / label 解析
→ 实际加载的 SWF
→ 是否属于公共特效组
→ 是否存在随机后缀或多个静态变体
```

如果多个武器都调用 `sub/motion_hit_effect`，应把它们视为同一公共特效依赖。恢复其中一组 2.5 特效时，需要考虑所有共用该调用的武器，而不能只针对小黄豆单独判断。
