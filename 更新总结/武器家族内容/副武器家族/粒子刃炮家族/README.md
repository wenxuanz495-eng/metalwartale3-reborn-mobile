- 受击 `sub/cutter_hit_effect` 为 cutter 公共受击名：当前 sub1130 的 #1509 内容被多家族共用（含 cutter/纳米号等），**任何受击改动严禁动本体**；若将来要做 2.5 细线版受击，须死名改绑路线单独立项。
