# 电弧音音量提升实验（待实机判定）

> 日期：2026-09-09
> 性质：**实验性修改**，用于验证"电弧音存在但音量过小"假设；依据用户实测结果决定保留 / 调倍数 / 回退。
> 关联：`守望者家族2.5-3.4-11.3对比审计-20260909.md` 第六节之二（电弧音频专项）。

## 背景与依据

- 用户实机反馈：游戏内听不到球状闪电放电的电弧音；两种可能 = ①找错音 ②未被调用或音量过小。
- 响度实测（ffmpeg volumedetect）：`lightningBall_lightning`（sound.swf cid 18）时长 0.6s，**平均 -26.7 dB / 峰值 -5.8 dB**——显著低于常规战斗音效（约 -12~-18 dB），"音量过小"假设成立。

## 实际修改（2 处）

1. `decompiled\gamefile\scripts\body\bullet\OneBulletBody.as` `lightningTimer()`：原 `Game.SG.playSound("lightningBall_lightning");` 改为取 OneSound 后 `play(1,4)`——**音量 ×4（约 +12 dB，预计平均 ≈ -14.7 dB）**，循环次数与原 playSound 一致；其余武器/音效零影响。
2. `config\build\swf-script-patches.txt`：追加 `body\bullet\OneBulletBody.as`（此前不在 123 项清单、不在禁改/风险清单）。

## 构建与验证

- `scripts\build_swf.bat` 退出码 0：导入 121 个脚本补丁 + 7 个 BinaryData；`build\game.swf` SHA-256 = `60EC1ADBD7BC5972F4EB8ED9C8CC26485BA67C8FFEC05DBC647F399F76A8A2D5`。
- 回读验证：从 `build\game.swf` 反编译 `body.bullet.OneBulletBody`，行 233-237 确认 `getSound` + `play(1,4)` 已在产物中。
- `scripts\launch_game.bat --check sa` 通过（Pure BAT prerequisites ready）。

## 待实机判定（用户执行）

启动游戏 → 装备守望者（LV1 即可）→ 1000px 内有敌人时开火放电，听电弧声是否可闻：

- **能听到** → 决定正式倍数（可调 2/3/4），再定稿归档；
- **仍听不到** → 排除"音量过小"，转向"调用链/触发频率"方向深查（音频设置存档 effectsVolume、`getRandom_Gap` 命中率、trace 日志）。

## 回退方式

还原 `OneBulletBody.as` 该处为 `Game.SG.playSound("lightningBall_lightning");` 并从 `swf-script-patches.txt` 删除该行，重新构建即可；当前状态已由 git 跟踪。
