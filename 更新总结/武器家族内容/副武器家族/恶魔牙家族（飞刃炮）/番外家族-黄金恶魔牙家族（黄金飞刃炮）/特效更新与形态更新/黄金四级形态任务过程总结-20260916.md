## 一、任务由来与定性

- 用户最初质疑飞刃炮双发机制，引出两个事实：双发=真实双发（bulletNum 驱动）；goldflyBlade 两级缺 bulletTranslation 导致双发重叠不可见（已补齐，见同日《黄金两级bulletTranslation双发错位补齐》）。
- 画师随后交付 `相关素材\黄金恶魔爪拓展\`：发射能量 1~8（金色发射特效八帧）+ 3~6 号四级新形态图（每级普通/发射微曝光双图）+ 核心特效 1~7（本批未用）。
- 用户拍板任务范围：①金色发射特效上 lv1/lv2（星座特效线）；②四级新形态导入 + 还原原版子弹挂点风格（新捏形态线）；③成长值 LV3~LV6 = +30/+40/+50/+60。
- 分类口径（用户定义）：**特效复古** = 回迁旧版素材与观感；**星座特效+新捏形态** = 以金色/星座审美为基础的新建内容。本任务全程属后者。

## 二、过程纪事（按实际发生顺序）

### 第 0 幕 · 侦察（决定成败的一天前置）

1. **等级机制**：`OneArmsDefine.getLabel() = id + "_lv" + (level+1)`——等级全动态，无 6 级硬上限，配置加几级生效几级；
2. **符号注册机制**：sub1130 的 253 个导出名 = SymbolClass（名字→角色 ID 平行数组）+ ABC 里 253 个存根类（dynamic MovieClip，声明 basePoint/shootPoint）——**新增名字必须双注册**；
3. **挂点组合真相**：本系 2.5 模板的本体形状素材**内部画着枪口顶弹**（2685/2689→2691 双本体互换），画师金体图无子弹——挂点弹需单独放置还原；
4. **素材组合关系**（用户纠正后确立）：黄金恶魔牙本体 = 363 枪体贴图 + 364 无拖尾反向弹 两层合成（枪上层/弹下层）；
5. **lv2 原版组合量测**：398 = 397(0,0) + 露出段 x72~92/y6~15（外露 15px，弹头中心对枪轴−2px）——新级的贴合基准。

### 第 1 幕 · 探针实验（避免把废案带进正式库）

- 假设"只加 SymbolClass 即可"→ 用 FP34 debug 探针（本地 http.server + 加载测试 SWF）实证：**加载即 ReferenceError #1065**——不可行；
- 手拼 ABC（FFDec XML 追加实例/类/脚本/方法/方法体，纯追加+回换断言）→ FFDec 能解析，**FP 校验器 VerifyError #1107 拒绝**——不可行；
- **定案**：mxmlc（AIRSDK，-compress=false -swf-version=43）正经编译 4 个存根类（dynamic MovieClip + basePoint/shootPoint 声明），提取 DoABC2 标签移植进 sub1130（SWF 多 ABC 合法）→ 探针复验通过。
- 附带产出：FFDec XML 常量池子项=AVM2 索引 0~N-1（无 +1）；mm.cfg 需 TraceOutputBuffered=0；FP 的 trace 缓冲会被强杀丢失——探针结果回传改用"实例上台+用户录屏"。

### 第 2 幕 · 资产与时间轴（两轮返工）

- **22 项新 ID 2756~2777**：8 本体位图+形状（4 级 × 普通/微曝光）、挂点弹位图/形状、4 条 11 帧时间轴精灵 2774~2777；SymbolClass 253→257；
- 时间轴逐帧镜像本系同级（891/888/885/882）结构，矩阵按金体 vs 本系本体的枪口/枪轴差重锚（Δ=(-240,70)/(-220,70)/(-260,20)/(-160,70) twips）；
- 第一版渲染"正常"是假象：待机本体（模板自带 depth=2）与挂点弹同置 depth 2，且 f2 的 RO d2 把换装体一并清掉——**实机表现为开火后整枪消失只剩蓄力特效（用户实机拦截）**；
- 修复：弹 d1 在下/枪 d2 在上、锚点抬到镜像占用深度之上；逐帧像素断言枪体区恒定 908+。

### 第 3 幕 · 挂点弹两轮返工（用户逐步纠正）

1. 初版裁 396 发射弹（带拖尾）硬贴且 f2 即移除——用户纠正：原版是 363+364 两层合成、开火也不消失；
2. 二版整颗 364 垫枪下——用户纠正：太大且脱离（画师枪体透明区盖不住整弹）；
3. **定稿**：只取原版组合体**露出段**裁剪（365 的 x79~94/y4~15，15x11 橙色箭尖），仿撒旦之力贴合：弹左缘=枪口列−6px（基部塞入枪口块下）、弹头中心对枪轴−2px、全程在场；逐列剖面断言 x70~110 无空隙列。

### 第 4 幕 · 配置与入库

- goldflyBlade 块追加 4 个 armsLevel（模板=lv2）：Growth_30/40/50/60、subAdd 0.4~0.7、Y_num100/150/200/300、commonLevel 60、hurt 1876、其余同 lv2；
- 事故与拦截：首版 setf 替换参数顺序写反（产出 `<name>name</黄金地狱之触>` 畸形节点，会砸烂整份配置解析）——被逐字段回读校验拦截，git 恢复重做；
- 终态：config=4E029EA1、sub1130=8E7E72E7（三处同步+manifest）、game.swf=CE46408C（binaryData 回读字节级一致）、构建 0、双自检 0。
