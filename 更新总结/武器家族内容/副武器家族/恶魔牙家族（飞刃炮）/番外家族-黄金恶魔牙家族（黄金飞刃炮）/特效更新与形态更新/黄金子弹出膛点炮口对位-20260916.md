# 黄金恶魔牙子弹出膛点（shootPoint）炮口对位 - 20260916

## 一、目标

用户反馈：子弹出现的挂点（shootPoint）距离枪口太远，应参照恶魔牙系列的挂点设计。

## 二、查证与设计

- 量测本系恶魔牙出膛点→炮口距离（本体坐标系，形状 bounds 偏移已换算）：
  - 本系 lv3 2685：炮口 (97.0,10.5)，出膛点 89.8 → **距炮口 −7.2px**
  - 本系 lv4 2713：炮口 (96.5,10.5)，出膛点 89.8 → **−6.7px**
  - 本系 lv5 884：炮口 (97.0,10.4)，出膛点 89.8 → **−7.2px**
  - 本系 lv6 881：炮口 (105.0,12.5)，出膛点 92.05 → **−13.0px**
  - 即本系口径＝**出膛点在炮口尖后方约 7px（lv6 约 13px）、位于炮管轴线**；
- 金体炮口/轴线（画师 PNG 量测）：lv3 (89,12.0)、lv4 (93,16.0)、lv5 (93,16.0)、lv6 (97,16.0)；
- 上一轮直接照搬本系绝对值 (1796,264) 后，出膛点换算到金体坐标仅 ~(69.4,0)px——距炮口 20~33px，且不在炮管轴线上——即用户所见"离枪口太远"。
