# 黄金四级新形态导入执行总结（LV3~LV6 + 子弹挂点还原）- 20260916

## 一、目标

用户指示：导入画师新交付的金恶魔牙 LV3~LV6 形态（`相关素材\黄金恶魔爪拓展\` 3~6 号图，每级"普通/发射微曝光"两张），并**还原原版挂点风格**——原版恶魔牙武器内部有子弹挂点，常态待机枪口顶着子弹。同批用户拍板成长值：LV3=+30、LV4=+40、LV5=+50、LV6=+60。

## 二、实际修改

### 2.1 结构侦察（要点）

- 原版挂点真相：本系 2.5 模板的本体**形状素材内部**画着枪口顶弹（形状 2685 等），lv1 另有"待机体 2689 → 开火体 2691"双本体互换；画师金体图**无子弹**，挂点弹需时间轴单独放置还原；
- 画师双图与本系双本体模式一一对应：f1 普通（待机）→ f2 起微曝光（开火）；
- 等级解析全动态：`OneArmsDefine.getLabel() = id + "_lv" + (level+1)`，无 6 级硬上限，配置加几级生效几级；
- 大圈链金链角色（2734~2755，前任务产物）与小白圈蓄力链（2652~2677）均为可共享角色，新级只做放置引用。

### 2.2 SWF 层（sub1130-lv36.xml 手术，模板 399 现行结构）

- **22 项新 Character ID 2756~2777**：
  - 8 本体 = 4 级 × (普通/微曝光) 位图+1:1 矩形包裹形状（2756~2771）；
  - 挂点组合弹 = 11.3 素材库 364 无拖尾反向弹，**水平翻转**后位图+形状（2772/2773，73x21）；
  - 4 条 11 帧时间轴精灵 2774~2777（= goldflyBlade_lv3~lv6）。
- **时间轴**（每级同构）：f1 待机本体 d2 + 锚点 104（basePoint/shootPoint，本系同级值+Δ）+ **挂点组合弹 d1（枪图层在上、弹图层在下，弹头伸出枪口 14px，全程在场不清除）**；f2 微曝光换装（枪层同深度替换）+ 枪口闪 2647 + StartSound 366；f3~f10 金链 d4（blend=5，2734~2755）+ 小白圈 d6 链；f11 清场——**逐帧镜像本系同级（891/888/885/882）结构，矩阵按"金体 vs 本系本体"的枪口/枪轴差（Δ=(-240,70)/(-220,70)/(-260,20)/(-160,70) twips）重锚**（沿 20260912 重锚先例）；

- sub1130：E7164ABF → BE18C6D9 → 05D8336A → A3028293 → 0777B8CD → **8E7E72E7**，三处同步 + manifest。
- **深度冲突修复（用户实机反馈拦截）**：首版把待机本体（TPL_BODY 模板自带 depth=2）与挂点弹同置 depth 2——弹的放置顶掉本体，且 f2 的"弹出膛"清除标签（RO d2）把换装后的枪体一并清掉，实机表现为"开火后整枪消失只剩蓄力特效"。修复＝弹 d1 在下、枪 d2 在上（同深度替换换装）、锚点抬升至镜像占用深度之上；逐帧像素断言：枪体区（x<45px）f1~f11 恒定 908+ 像素。
- **挂点弹素材返工（用户纠正后）**：首版裁剪 396 发射弹（带白色拖尾）硬贴，且 f2 即移除——与原版不符。用户指出原版组合关系：**黄金恶魔牙本体 = 363 枪体贴图 + 364 无拖尾反向弹 两层合成（枪上层/弹下层）**。像素对位实证：365 内 363 于 (0,0) 完全吻合，翻转 364 以 (19,−1) 叠入、弹头（橙色）伸出枪口 14px 与露出段颜色（RGB 176,79,22 ≈ 弹头橙）完全吻合；且**开火时组合弹不消失**（弹 d1 不做清除，换装只替换枪层）。**最终定稿（用户二次纠正"太大/脱离"后）**：挂点弹不再整颗 364 入场，改为原版组合体露出段裁剪（365 的 x79~94、y4~15 = 15x11 橙色箭尖段），放置仿撒旦之力贴合：tx=(枪口列−6)px（弹头基部塞入枪口块下 6px）、弹头中心对枪轴−2px，露出 ~15px；逐列剖面断言 x70~110 无空隙列（枪体与弹连续）。

### 2.3 ABC 存根类（本任务核心技术点，两级失败教训 + 最终方案）

新导出名需 **SymbolClass + ABC 存根类**双重注册，本项目首次走此路径：

1. **探针实验一**：仅加 SymbolClass（无类）→ Flash 加载即 `ReferenceError #1065`（变量未定义）——不可行；
2. **手拼 ABC（FFDec XML 追加实例/类/脚本/方法/方法体）**：FFDec 宽容可解析，但 **Flash Player 校验器 `VerifyError #1107 ABC 数据已损坏`**——不可行；
3. **最终方案：mxmlc 正经编译 4 个存根类**（`public dynamic class goldflyBlade_lvN extends MovieClip`，声明 basePoint/shootPoint，AIRSDK `-compress=false -swf-version=43`），提取各产物 DoABC2 标签（329B ×4）**移植**进 sub1130-lv36-final.swf 的 SymbolClass 之前（SWF 允许多 ABC 标签）——**运行时验证通过**（见 2.5）。
- 附带发现：FFDec XML 常量池子项直接对应 AVM2 索引 0~N-1（首 isNull 项 = 0 号"*"）；mm.cfg 需 `TraceOutputBuffered=0` 否则 trace 缓冲丢失。
