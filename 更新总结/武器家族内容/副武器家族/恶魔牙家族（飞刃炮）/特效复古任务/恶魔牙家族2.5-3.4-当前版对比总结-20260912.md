## 三、②子弹贴图 / 受击特效（A3 / A5）

### 子弹（三版零差异，证据等级 A）

- 配置三版全形态共用 `sub/flyBlade_bullet`；

### 受击（整套更换，证据等级 A）

| 版本 | hitImgLabel | 实物 |
|---|---|---|
| 2.5 | 裸名 `chipped_hit_effect` | sub37 #1632：**8 帧大型星芒绽放**（白核→星刺→蓝色花瓣展开＋飞散火花→消散） |
| 3.4 | `bullet/blue_motion` | bullet.swf #94：**4 帧小型蓝色拖曳光斑**（f1 光球→f2~f3 拉长消散→f4 清理帧） |

## 四、③待机 / 开火状态 / 枪口火焰（A1 / A2 / A6 / A7）

### 时间轴骨架（三版同构：11 帧）

```text
f1 待机（本体 + basePoint/shootPoint 命名挂点）
f2~f10 开火表演
f11 清理/回归
```

挂点实证：2.5/3.4 用角色 110（lv1@d19/d21，lv2~5@d7/d9），GH 用角色 104（d4/d6；黄金 d5/d7）——**命名实例 `basePoint`/`shootPoint`，实机被 SWFLoaderManager 隐藏，导出图中的红色方框加号标记不是美术**（元素键 C1）。

### 本体逐像素比对（内容包围盒对齐法）

| 形态 | 2.5 vs 3.4 | 3.4 vs GH |
|---|---|---|
| lv1 | **11/11 帧逐像素一致** | f1 待机内容一致；**画布重排 183×110→147×80**；f2~f11 内容宽 +2px（106 vs 104） |
| lv2 | 一致 | 待机帧差异 11~12.7%，开火峰值 1.2% |
| lv3 | 一致 | 待机 9~10%，峰值 1.2%（f3/f4 内容高 ±1px） |
| lv4 | 一致 | 待机 7.8~9.1%，峰值 1.1% |
| lv5 | （3.4 新增） | 待机 7.7~9.2%，峰值 1.3% |
| lv6 | —（GH 独有） | 更大双红刃本体（待机内容 106×35） |

结论：**本体美术的改动全部发生在 3.4→当前版（11.3）**，性质为炮口红色能量刃的细微重绘（形状不变、色阶重排）＋lv1 画布重排；2.5→3.4 期间本体零改动。

### 开火链结构（最大结构性差异，证据等级 A）

**2.5 / 3.4（两者同构，角色号不同）：**

```text
f2: 换开火本体 502/767@d1（lv1 专属）＋ 4 层 blend8 蓄光 520×4@d3/6/9/12 ＋ 闪光 522@d15
    （lv2~5 无本体互换，改放专用闪光 454/716@d4）＋ StartSound 455/717
f3~f8: 枪口逐帧序列 460,465,470,475,480,485 @d2/d6（6 帧，即黄金档案所指"枪口烟雾/能量"组）
        ＋ blend5 辉光 458~483 @d17/d4
f9~f10: 辉光衰减 488,491 / 750,753
f11: 清理
```

**当前 GH（全家族＋黄金统一模板）：**

```text
f1: 本体（逐级独立形状）+ basePoint/shootPoint
f2: 仅 StartSound 366（无本体互换、无专用闪光）
f3~f10: 共享 8 帧 blend5 辉光 369~390（lv1~lv6＋黄金 lv1/lv2 全部共用同一组）
f11: 清理
```

差异实质：GH **没有** 2.5/3.4 的"f2 开火本体互换（lv1）＋lv1 四层 blend8 蓄光＋枪口 6 帧序列"，改为单层共享辉光；且 GH 把辉光/音效全部家族化共用。

### 音效（A7，证据等级 A）

- 开火音：2.5（#455）= 3.4（#717）**MP3 字节级一致**（7800B）；当前版（#366）**为不同音效**（同尺寸不同内容）。
- 受击音：随 blue_motion 的 StartSound 57，3.4 与 GH 字节一致。
- 时间轴均含 SoundStreamHead2 流式音轨头。
