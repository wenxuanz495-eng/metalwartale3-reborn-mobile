## 五、修改操作速查（常见任务 → 要动的行）

- **改某部位位置** → 二节对应行「当前态锚点值」即脚本断言基线；改完先更本表再归档。
- **换某部位贴图** → 二节行拿位图 ID 与 PNG 路径；新图必须逐像素验证后替换位图内容，字符 ID 不变（同深度替换禁令只针对时间轴放置，不影响位图像素更新）。
- **新增逐帧动画** → 先读 `..\..\..\新建武器（形态）方法总结\时间轴动画替换失效修复与标准写法\`（RO+add 红线），再按 `MK2蓄力` 行的帧位格式登记。
- **动弹道** → `MK?出膛点` 行 + `弹距lv?` 行联动换算（真弹线 = 出膛点.y ± 弹距，两行配平可实现单边移动）。
