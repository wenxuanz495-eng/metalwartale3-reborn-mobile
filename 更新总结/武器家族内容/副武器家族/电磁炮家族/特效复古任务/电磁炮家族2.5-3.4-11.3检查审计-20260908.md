## 三、检查结果（四项对照）

### 总判断

**2.5 与 3.4 高度一致**——攻击数值、成长线、全部精灵逐字节相同；3.4 仅变了三处：①受击特效调用 `sub/motion_hit_effect`→`bullet/purple_motion`（唯一实质变化，四形态全改）；②lv4 名称去掉间隔点"EX·超电磁炮Z"→"EX超电磁炮Z"；③mustItems 由数字标签改为命名物品标签（数量比例不变，纯格式）。
**3.4 与 GitHub(11.3) 的差异才是主体**，且**不在本体美术**（四级本体位图逐字节相同）：①电弧动画层被删（12/13 帧 ADD 层→无）；②子弹美术由"逐级独立（lv3/lv4 双层）"改为"四级共用一张 61×40"；③lv1 射速减慢、全家族后坐力加大；④受击特效与 3.4 持续一致。成长线重新平衡（本文不展开）。

### ② 子弹与受击（A3/A5）

- **受击 hitImgLabel**：2.5 = `sub/motion_hit_effect`（与小黄豆/火神炮共用的公共受击特效，运行时随机 `_1~_4` 变体）；**3.4 与 GitHub 均为 `bullet/purple_motion`**。即这一项是 3.4 时代的改动，11.3 沿用——与小黄豆案例（GitHub 独有 yellow_motion）方向相反。
- **子弹美术（位图级）**：

### ③ 本体待机/开火状态与枪口（A1/A2/A6）

> ⚠️ 本节为 2026-09-08 第二次修订。初版误判"2.5 红白炮体、11.3 蓝白板型整体重设计"：红色实为挂点标记（用户指正）；"蓝板 vs 白炮"则是 FFDec frames.gif 调色板渲染＋2.5 画布含电弧/标记造成的假象（用户再次指正"视觉效果几乎一模一样、只是画布改变"）。**位图级复核证实本体美术逐字节相同**。

- **本体位图（真美术）四级全部逐字节一致**（2.5 与 GitHub 的 DefineBitsLossless2 zlib 数据 SHA 相同）：
  - lv1 48×20（`f37222a2…`）、lv2 65×19（`cc2cbe6e…`）、lv3 61×23（`4ab89660…`）、lv4 83×25（`92ff1fd0…`）
  - 形状定义同构：同边界（如 lv1 X320-1280/Y160-560 twips）＋同为"位图矩形造型"（1 StyleChange + 4 StraightEdge）＋真身位图填充（65535 为遗留空填充，真图在第二填充）
  - 渲染证据：`elecGun-真本体位图对比-2.5vsGH-20260908.png`（两列像素一致）
- **差异在时间轴构成（"画布"差异）**：
  - 2.5（sprite 1603 等，画布 98×65/181×122）：深度1 本体（静态）＋深度2 **12/13 帧逐帧 ADD（blendMode=8）电弧叠加层**（角色 1569/1572/…/1602）＋深度4/6 可见红色挂点标记
  - GitHub（sprite 1417 等，画布 53×21/101×26）：同一本体位图＋**无任何电弧层**＋标记实例在声明边界外不可见＋仅 2 次深度1 矩阵位移（7 帧）＝本体位移抖动动画
- **红色元素 = 挂点辅助标记（非美术）**：`basePoint`（深度4/2，565,380 twips）与 `shootPoint`（深度6/4，1200,380 twips），实例化角色 110→形状 109（2.5，红色方格+十字，13.5×13.25px）；GitHub 角色 104→形状 103，**矩阵与形状边界逐字节相同**，**FFDec 静态导出中标记可见（2.5 尤其醒目），但实机两版均被 `SWFLoaderManager` 隐藏**（按名扫描→读坐标→`visible=false`＋缩至 0.1，2.5 代码库 `net/SWFLoaderManager.as` 与仓库同文件 2026-09-09 双重证实）——红标记不构成实机差异。运行时 `SingleMovieclip.basePoint/shootPoint` → `SubImage.get shootPoint()` → `ArmsAttack.shoot()` 为功能锚点。
- 结论：**本体美术与挂点锚位两版完全一致；真实差异=2.5 多了电弧动画层，11.3 只剩本体位移（标记实机两版均隐藏，不构成差异）。回迁电弧=重建 ADD 叠加层序列，本体位图无需动。**
- 证据图：`elecGun-2.5vs11.3-对比图-20260908.png`（初版对比图，11.3 列受 GIF 调色板影响仅供结构参考）、`elecGun-真本体位图对比-2.5vsGH-20260908.png`（位图级真相）、`elecGun-2.5-lv1-红色标记放大-20260908.png`、`elecGun-2.5-lv4-frame1-6x-20260908.png`。
