# 电磁炮家族 电弧蓄力特效图集（2026-09-09）

来源：当前已回迁的 `swf\sub1130.swf`（SHA-256 前 8 位 `cea95884`）四级本体时间轴，逐帧解码渲染。

## 内容

- `lv1\` ~ `lv4\`：每级**合成后单帧图**（枪体＋该帧电弧，即实机观感；挂点标记按实机隐藏不渲染）。
  - 帧01 = 待机（裸枪体）；帧02~帧13 = 电弧循环（每帧一张独立闪电图，ADD 发光叠加）。
  - 文件名：`lvN_帧NN_状态.png`，3 倍放大。
- `lvN-电弧蓄力全帧总览.png`：每级全帧横排总览（带帧号）。

## 技术说明

- 帧序与放置矩阵取自本体时间轴（elecGun_lv1~lv4，13/14/14/14 帧），位图为 DefineBitsLossless2 逐字节解码（ARGB）。
- 渲染画布为各帧内容并集，闪电图按时间轴矩阵定位，与游戏内合成方式一致（除 ADD 混合以 alpha 叠加近似呈现）。
- 对应关系：lv1 12 张电弧图、lv2/lv3/lv4 各 12 张（14 帧中 2 帧为停留帧）。
