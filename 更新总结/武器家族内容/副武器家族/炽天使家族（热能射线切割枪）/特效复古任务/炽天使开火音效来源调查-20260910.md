# 炽天使开火音效来源调查（Intercessor 仲裁者/判决者）

> 调查日期：2026-09-10
> 背景：用户与群内玩家记忆中"热能射线切割枪有较低的持续开火音"，但实测三版本玩家武器均无声；且同为持续激光的战殇（laser）同样无声。

## 一、已证实的硬数据（A 级证据）

1. **玩家武器侧零音频**：炽天使 lv1~lv5 本体、hot_hit_effect、战殇 laser 全系、laser_lv1_bullet0、skill_laser_body/bullet——在 2.5 sub37、3.4 sub52、GH sub1130 中均**无 StartSound、无音频流数据块**（全文件扫描；sub1130 另 129 处 StartSound 属其他武器）。parts.swf/bullet.swf 亦无对应音。
2. **音源在 Intercessor.swf（仲裁者/判决者共用敌人包）**：三版本该文件**字节完全相同**（音效从未丢失）。内含 11 个 DefineSound、26 处 StartSound，全部内嵌在 shoot_* 攻击动画时间轴里：

| 动画（导出名→精灵ID） | 总帧 | 音效触发（帧，音效ID） |
|---|---|---|
| shoot_1 (532) | 29 | f4→531、f7→531 |
| shoot_2 (520) | 27 | f1→223、f4→222、f12→223 |
| shoot_3 (368) | 46 | f3→223、f6→222、f14→223 |
| shoot_4 (291) | 41 | f3→222、f3→223、f9→236、f14→223 |
| shoot_jump (315) | 29 | f1→219（带音量包络）、f10→294、f15→294 |
| shoot_attack (221) | 28 | f1→219、f15→220 |

3. **Boss 行为结构**（Intercessor_AI.as）：仲裁者（heroState="intercessor"）→ 70% 概率变身为判决者（changeState("adjudicator")）；判决者按概率轮换 shoot_3 / shoot_jump / shoot_attack / shoot_4 四技能，且 shoot_attack/shoot_4 会改变碰撞盒等级（rectLevel 2/1）。
4. **Boss 激光技能是代码硬编码**：xmlClass9（enemyArms）中只有占位条目 `Intercessor`/`Intercessor_jump`（名字"仲裁者-拉屎"、太阳炮 bullet 型、无 imgLabel），**不存在**"热能射线切割枪/热能射线冲击炮"的敌人武器配置；全部配置文件中"热能射线切割枪"仅出现在玩家 xmlClass7 的 hotline 块。
5. 试听文件：`开火音候选-20260910\`（命名=音效ID-触发位置-时长，无用途标注）。

## 二、推断（非数据结论，待用户耳朵验证）

- "531=基础切割枪开火音"是**推断**：理由=①shoot_1 是唯一"单音效重复触发"的动画（f4/f7 两连发节奏）；②shoot_1 不在判决者四技能轮换列表里，更接近仲裁者的基础攻击；③音长 1.5s 与玩家版攻击节奏（attackGap 1.5s）巧合吻合。但 shoot_1 的实际触发路径（Enemy_AI.startAttackOnce_break 走 ArmsAttack 状态机）未逐帧验证，且 Boss 动画≠玩家武器动画，音画同步点需另测。
- 其余"蓄力/灼烧/余韵"等描述性名称均为早期推测，已从文件名移除。

## 三、修复方向（待用户决策）

玩家版要出声只能**主动借用** Boss 音效（新 ID 导入 sub1130 + 在炽天使/战殇时间轴开火帧挂 StartSound）。需要用户决定：①选哪段音（试听后定）②五级同音还是分级 ③挂载帧位（建议光束出现帧，逐帧核对后定）④战殇是否同批处理。

## 四、最终判定（2026-09-10 视频音频比对 + 用户试听确认）

用户提供两段实机录音（切割枪 1.71s / 冲击炮 0.87s），与 11 个候选音做多方法比对（全段频谱相关、谱减法提取+平均谱、峰值指纹、2D 声谱互相关）：

- 视频录音存在 BGM 混叠，且视频1 尾段混入音效43（Boss 死亡音，录制时光束击杀 Boss）。
- 光谱分析初判：视频1→223（3.23kHz 峰）、视频2→222（7.04kHz 尖峰唯一匹配）。
- **用户试听最终裁定（以此为准）：222 = 切割枪开火音效；236 = 冲击炮音效；223 = 切割枪受击音效（后续追加挂载）。** 222/236 为同族姐妹音，与用户"两武器音效非常相似"的记忆一致。
- 早期按位置推测的"531=基础切割枪开火音"推断作废；"灼烧/蓄力"等描述性命名均已撤销。

## 五、实施结果

- DefineSound 222 → sub1130 新 ID **2294**；DefineSound 236 → **2295**（音频数据哈希与 Intercessor 源逐字节一致：6C3C4165…/EB96B93A…）。
- hotline lv1(1171)/lv2(1160)/lv3(1149) 第 2 帧插入 StartSound→2294（切割枪音）；lv4(1107)/lv5(1104) 第 2 帧 →2295（冲击炮音）。第 2 帧 = 光束层(char 1067)出现帧，即开火同时。
- soundInfo 采用与响尾蛇开火音相同的透传模式（不循环、同步释放）。
- 构建 + 三处同步 + manifest 已更新，双自检通过；画面放置零变化（回读断言）。
- 待实机确认：音量是否合适（Intercessor 内这些音按 Boss 动画音量混音）、连续射击时音效衔接（222=2.04s、236=2.43s，attackGap=1.5s 存在 0.5~0.9s 重叠）。
