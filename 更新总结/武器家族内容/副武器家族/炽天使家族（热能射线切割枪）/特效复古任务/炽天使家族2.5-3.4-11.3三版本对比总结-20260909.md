# 炽天使家族（热能射线切割枪）2.5-3.4-11.3 三版本对比总结

> 对比日期：2026-09-09
> 性质：🔍 **只读对比审计，全程未修改任何游戏文件**
> 家族：副武器 `arms id="hotline"`（xmlClass7 index=5），五形态炽天使/伊夫利特/不死鸟/洛基/凤凰
> 参照版本：2.5（`sub37.swf` + `subArms37.xml`）、3.4（`sub52.swf` + `subArms52 xml`）、GitHub 当前（`sub1130.swf` + `xmlClass7.bin`）
> 工作区：`D:\superalloy\tmp-soya-family-test\hotline-3ver-audit\`（脚本 chain2_hotline.py / compare_hotline.py，导出 XML、渲染帧、结构 JSON 均在此）

## 一、目标

按《武器视觉效果构成元素键》A 类美术资产逐项对比三版本差异：A1 本体时间轴（含 A2 开火光效/枪口火焰、A6 待机光斑）、A3 子弹/激光束本体、A4 拖尾、A5 受击特效、A7 音效，附 C1 挂点核对；配置层同步核对美术相关字段。

## 二、对比方法与证据

1. 三版本配置块提取逐字段 diff（`work/hotline_*.xml`）；
2. 三版本 sub SWF 经 FFDec swf2xml 后自研解析器提取 SymbolClass 映射、精灵时间轴逐帧放置（深度/角色/命名/混合模式/矩阵/比例），定义块按缩进定界；
3. 形状→位图数据哈希（zlib/jpeg/alpha 数据 SHA-256）跨版本内容匹配，排除 Character ID 重编号干扰；
4. FFDec sprite 全帧渲染（30 帧×5 级×3 版本 + 受击 6 帧×3 版本）+ PIL 逐像素差分；
5. 证据图 4 张存本目录（待机五级三版、差异高亮、受击六帧、受击六态标注图）。

### 3.3a 受击六态量化补充（2026-09-10）

- 2.5 六态两两像素差 2487~3075 px（约占单态非透明像素 11020 px 的 23%~28%）——每态都是独立绘制的碎片/灼痕分布，非微变体。
- 六态内容量相近（2937~3155 px），属"闪烁演化"型爆炸而非膨胀生长型：逐帧碎片位移+灼痕变化，6 帧连续播放观感细腻。
- 3.4/GH 六帧与 2.5 的对应经渲染逐字节比对锁定：f1=f2=态1、f3=f4=态3、f5=f6=态5；3.4 与 GH 六帧完全相同。

## 三、对比结论

### 3.1 配置层（美术相关字段零差异）

| 字段 | 2.5 | 3.4 | GH |
|---|---|---|---|
| imgLabel | hotline_lv1~lv5 | 同 | 同 |
| hitImgLabel | sub/hot_hit_effect | 同 | 同 |
| bulletImgLabel / smokeImgLabel | **无**（激光型，同战殇） | 无 | 无 |

- **形态三版一一对应**：炽天使/伊夫利特/不死鸟/洛基/凤凰，无新增、无改名、无 ID 错位。
- 行为差异仅 1 项：`attackGap` 2.5=3.4=`1.5` vs GH=`2.4`（五级一致；3.4→11.3 改慢，同响尾蛇/调皮/战殇模式）。
- 经济/成长字段差异（commonLevel、mustItems、price）按禁令仅登记，不属美术。
- 战斗字段 hurt 90/100/111/134/134、bulletWidth 15/20/25/35/35、bulletLife=0.7、penetrationB=1、attackDelay=0.2 三版一致。

### 3.2 A1/A6 本体与待机光斑（A 类，3.4=2.5，GH 删减）

**位图内容三版完全一致**：本体五级位图（43×24 / 51×26 / 66×29 / 78×31 / 80×29 px）、激光束长条层（d1，位图 `5028E8FC03D7`）、开火烟雾四态循环（d3）逐字节相同。

**时间轴结构 2.5=3.4 完全一致，GH 删减 ADD 光斑层（blend=8）**：

| 形态 | 2.5=3.4 放置数 | GH 放置数 | 被删内容 | 待机 f1 可见差异 |
|---|---|---|---|---|
| lv1 | 39（34 个 blend8） | 5 | 全部 34 个枪口/炮身光斑 | 差 1682 px（枪口光点消失） |
| lv2 | 39（34 个 blend8） | 5 | 同上 | 差 2060 px |
| lv3 | 51（47 个 blend8） | 17 | 炮身光斑+第二份脉冲系列 | 差 2768 px |
| lv4 | 43（39 个 blend8） | 17 | 炮身光斑 | f1 无差异（被删层不在 f1） |
| lv5 | 43（39 个 blend8） | 17 | 同上 | f1 无差异 |

- GH lv3~lv5 保留的 13 个放置 = x=11527 脉冲光斑系列（13 个矢量光斑），2.5/3.4 该系列正放+倒放各一份（尾部逐帧扫掠动画），GH 只保留一份且扫掠帧率减半。
- 开火帧差异（lv4/lv5 实测 f4~f13 共 21/30 帧有差异，每帧 1.4万~2.8万 px）：沿激光束的 ADD 闪光/火花层被整体删除，光束本体仍在。
- 本体 30 帧循环结构三版一致：f1 待机 → f2 起开火烟雾四态循环（GH 保留）→ 尾部脉冲扫掠。
- 被删的 34 个光斑形状（23 个独立美术签名）经全域扫描**在 GH sub1130 中不存在**——回迁需从 2.5 迁移资源，非改绑可得。

### 3.3 A5 受击特效（2.5 六态 → 3.4/GH 三态，响尾蛇/战殇同模式）

- 2.5：六帧六态，六张独立 JPEG3（状态哈希 `CA120498…`/`7C74578B…`/`5C0C24D4…`/`E959A8FA…`/`11F0DF65…`/`25BA159A…`），每帧推进一态。
- 3.4 与 GH **逐字节相同**：六帧三态，仅沿用 2.5 的第 1/3/5 态各播两帧（渲染像素比对证实：3.4 f1=f2=2.5 态1、f3=f4=2.5 态3、f5=f6=2.5 态5）。
- **缺失的第 2/4/6 态三张 JPEG3 在 GH sub1130 中不存在**——受击回 2.5 六态需小成本资源迁移（同战殇家族受击情形）。
- 三版受击精灵均无 StartSound、无内嵌音效差异。

### 3.4 A7 音效、C1 挂点与运行时机制

- **音效**：三版本 hotline 全部六个精灵（本体×5+受击）均无 StartSound、无 DefineSound 引用——本武器开火/受击音效路径与时间轴无关，三版零差异。
- **挂点**：`basePoint`/`shootPoint` 位置三版逐字节相同；2.5/3.4 挂点标记字符=110，GH=104（已知更替）。按通用结论挂点实机隐藏，不构成美术差异。
- **随机后缀**：`hot_hit_effect` 不匹配 `motion_hit_effect` 命名规则，运行时原样透传，无 `_1~_4` 变体问题。
- **激光束机制**：无 bulletImgLabel；光束为武器时间轴内 d1 长条位图层（三版同图），配合 MaskArmsImage 按射距展开（见《未完成重点任务\感应炮追踪目标优先级改进》对 hotline/laser 光束机制的记载）。

### 3.5 证据等级

- 形态映射、配置差异、位图/形状同源性：**A 级**（配置+SWF 结构+渲染像素三重互证）。
- 受击六态→三态更替、待机光斑差异：**A 级**（渲染逐像素+位图数据哈希）。
- 开火帧 ADD 闪光层删除：**A- 级**（结构+差分像素证实；实机动态观感未测）。
