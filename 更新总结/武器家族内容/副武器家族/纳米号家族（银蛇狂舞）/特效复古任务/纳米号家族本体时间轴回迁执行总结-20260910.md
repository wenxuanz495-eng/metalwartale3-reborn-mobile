## 三、追加批次：银蛇枪口焰红方块修复（同日实测反馈）

**实测反馈**：银蛇枪口火焰出现大红方块（金蛇正常）。

**根因（二进制 dump + 填充反查证实）**：本批次导入的角色 ID 从 2421 起，与上一轮克隆的两条**音效** ID（2421=碎裂炮开火音、2422=银蛇开火音）撞号——SWF 字典为**单一命名空间**（含音效），Flash 先注册者生效，后到的焰形填充位图定义 2421/2422 被丢弃 → 引用它们的形状 2443（f10 枪口焰）与 2448 填充解析失败 → **红方块=缺位图填充**。FFDec 双命名空间模型渲染正常，故此前的 FFDec 像素验证无法发现该问题。金蛇导入区间（2463~2508）无撞号，故正常。

**修复**：ID 分配算法改为把 soundId 一并计入最大占位（snake_body_merge.py max_char_id），从 744837DA 中间态重跑合并——银蛇闭包改为 **2423~2464**、金蛇 **2465~2508**；重申 2.5 版本验证：**两级 25 帧 vs 各自模板逐像素 0.00%**；全文件 ID 唯一性断言 PASS（总定义 2503）；焰形填充指向音效 ID 计数=0；SymbolClass 253 不变；构建退出码 0（sub1130=**B9C46C9D** 三处同步+manifest、game.swf=45E13646 未动属预期）+sa/sa_debug 双自检通过。

**经验入库（红方块教训第二例，升级通用条款）**：FFDec XML 合并脚本分配新 ID 时，max 基线必须覆盖 characterID/shapeId/spriteId/**soundId** 全部四类——角色与音效同属一个字典；同时"FFDec 像素验证 0 差异"不能覆盖 Flash 特有的缺位图渲染（红块），涉及跨包位图导入时须实机验证焰/光类填充。
