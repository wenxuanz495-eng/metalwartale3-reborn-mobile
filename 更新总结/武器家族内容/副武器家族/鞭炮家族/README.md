## ⚠️ 命名区分（先读）

- 本家族武器名称为**鞭炮**（鞭炮 / 鞭炮II / 鞭炮2016 / 鞭炮2017），武器类型 `type=转移炮`——"转移炮"是类型名，不是武器名。
- **与主武器"相转移炮家族"（arms id="phaseTransfer"，档案 `..\..\..\..\主武器家族\相转移炮家族`）严格区分**：两者名字相近（2.5 文案里鞭炮即"根据相位转移炮的特点制造"的致敬产物），但分属两套体系——本家族是 subArms 副武器体系（xmlClass7 配置 + sub1130 等资源分包），相转移炮是主武器体系（xmlClass3 配置 + arms1100.swf）。配置、资源、档案均不可混用。
- 番外家族**黄金鞭炮**（arms id="Goldbanger"，type=黄金转移炮）已按用户安排独立建档：`番外-黄金鞭炮家族\README.md`。
