## ⚠️ 命名区分（先读）

- 本家族武器名称为**黄金鞭炮**（黄金鞭炮 / 黄金鞭炮MK2），武器类型 `type=黄金转移炮`。
- **与"相转移炮家族"（主武器 phaseTransfer）无关**：名字里都有"转移"二字，但本家族是 subArms 副武器体系、是鞭炮（banger）的黄金派生，与主武器相转移炮无任何配置或资源关联。
- 配置 / SWF 中 id 拼写为 **`Goldbanger`**（大写 G 开头，与其余小写驼峰 id 风格不一致），检索时注意。

## 立项预检线索（只读核对，未做全面对比；正式对比时范围按用户安排）

- **2.5 / 3.4 无黄金鞭炮资源**（两版 subArms 配置中 Goldbanger 出现 0 次）→ **不存在"黄金本体回 2.5"**。`banger-gold-restore` 报告原文："2.5 没有独立黄金鞭炮资源，因此黄金本体不能声称为 2.5 本体；本次只恢复其发射动画和子弹动画。"
- 黄金派生惯例（黄金恶魔牙 / 黄金深渊先例）：MK2 按黄金派生通常沿用 lv1 / 家族特效；黄金配色本体属后续版本演化物，其定位（视为演化保留还是需要做旧）须与用户确认基调。
- **子弹联动项**：与本体家族共用 `sub/banger_lv1_bullet`——本体家族若回迁 2.5 子弹资源，本家族飞行弹视觉将同步变化，执行时须两家族一并验证。
- **受击同名异实物风险**：`sub/cutter_hit_effect` 为公共受击特效名；纳米号家族对比记录过该名下 2.5（细线 173×13）与 3.4=GH（宽线 221×25）的资源差异。若考虑受击回迁，先取 `..\..\2.5受击特效提取-20260909（文件夹）` 基准包核对，不可原位替换。
