
本次新沉淀的管线坑（后续合并脚本必查）：

1. **FFDec 的 DefineSpriteTag 带双 ID 属性**——`spriteId`（xml2swf 实际采用）与 `characterID`（别名）。重映射 ID 时**两个都必须改**，只改 characterID 会导致符号按旧 ID 写出、导出映射整体落空（本次 lv1/lv2 首轮消失的根因）。
2. **FFDec CLI 的 `-select` 是帧范围不是角色 ID**——按 Character ID 导出帧须用 `-export sprite` 整包导出后取用。
3. **手插 move 型 PlaceObject（纯 CXFORM 变换）在 FFDec 渲染器下不生效**——给既有深度叠加"逐帧渐变"层时，应连同其放置与变换整体搬入原版序列（本次 lv3/lv4 蓄力层首插不显的根因），或以"包装 sprite 内自包含序列"实现。
4. **判定 sprite 画布/位置要看原尺寸渲染**——搬入外部序列可能撑大 FFDec 导出画布（内容 bounds 重算），缩略对比会失真，实机以放置矩阵合成为准。
