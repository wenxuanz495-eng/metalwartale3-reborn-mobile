## 发射机制解剖（2026-09-17，本家族核心资料）

sprite 551 共 **18 帧**，一条完整的"带弹 → 发射 → 装填"弹舱故事：

| 帧 | 内容 |
|---|---|
| f1~f4 | 待机：本体 537（**带弹版**全本体 132x35px，原点(-7,0)，导弹画死在本体图里、盖住筒口内半环）＋basePoint（d5，62.45,17.85px）＋shootPoint（d7，136.45,17.35px） |
| f5 | StartSound（**开火音 108**——与 zhongzifeidan lv1/lv2 三方共用，动音效须新增 ID） |
| f6 | 本体 537 移除→**空膛版本体 538**（与 537 **同画布** 132x35px、原点相同，筒口露出）置于 d3；**带尾焰的导弹 539** 置于 d4 从炮口起飞（66x91px，含高 tall 尾焰 plume）；发射视觉全部从本帧开始（音提前一帧） |
| f7~f11 | 飞弹链 d4 逐帧 MOVE：541(76x99)→542(75.5x98)→544(75x103)→545(48x61)→547(28x42)，**渐飞渐小** |
| f12 | **装填开始**：d1 放置 549＝单帧精灵，内部为形状 548（**仅 27.5x12.8px 的单枚导弹小精灵**，叠在仍在本场的空膛本体 538 之上）；d4 尾焰末帧 550 替换（26.6x38.9） |
| f13 | d4 尾焰清除；d1 导弹小精灵开始 MOVE |
| f14~f16 | d1 连续矩阵微移＝**导弹滑动入膛的装填动画** |
| f17~f18 | 收尾；循环回 f1（537 带弹版与"538+549"组合观感等价） |

**角色清单（含 bounds，px）**：537 带弹本体 132x35@(-7,0)｜538 空膛本体 132x35@(-7,0)（与 537 同画布成对）｜549 回场装填精灵（内含 548 单枚导弹 27.5x12.8@(0,-6.3)）｜飞弹尾焰链 539=66x91@(86.5,-27.9)、541=76x99.3@(80.8,-28.9)、542=75.5x98.2@(82.3,-25.1)、544=75x102.7@(82.6,-27.4)、545=48.3x61@(100.3,-16.1)、547=28.3x42.2@(100.3,-3.5)、550=26.6x38.9@(99.5,-1.5)｜弹 535（单帧精灵）内层形状 534=62.1x25@(-33.1,-11.5)（**弹图原点在可见弹体左侧偏下——E2 贴图内部偏移教训的典型样本，任何"出膛点对位"先量内部偏移**）。

**机制要点（可借鉴结论）**：

1. "带弹↔空膛"用**两张同画布全本体图整体切换**（537↔538）表达，装填用**单枚导弹小精灵放置＋滑动**（549+MOVE）表达——三层分离，各司其职；
2. 开火音比发射视觉提前 1 帧（f5 音、f6 弹出）；
3. 导弹飞离＋尾焰整套画在武器时间轴内（7 帧渐飞渐小）——仅适用于"弹在时间轴里飞"的设计；星际雷神这类运行时出弹的武器不能照搬（其 v1 已按双份独立尾焰实现，见星际雷神家族档案）；
4. 锚点深度 d5/d7（非常见的 d3/d5），动本家族时间轴时按深度规划三原则核查冲突。

**勘误**：`星际雷神家族皮肤与发射特效替换执行总结-20260917.md` 中"killPig f12 本体换回 549 带弹版"的表述不够准确——549 实为**单枚导弹小精灵**（叠于空膛本体 538 之上）＋f13~f16 滑动装填，以本档案为准。
