## 分类边界

- **主武器家族**（`..\主武器家族\`）：战车主炮体系，配置在主武器 XML（`decompiled\embedded-xml-assets\2_EmbedXml_xmlClass3_...bin` 的 `<arms>` 节点），资源在 `arms1100.swf`。
- **副武器家族**（本目录）：副武器体系（浮游战机、火箭/导弹等），对应 subArms 配置（`decompiled\embedded-xml-assets\6_EmbedXml_xmlClass7_...bin`）与 `sub1130.swf` 等资源分包。
- 跨主/副的代码机制、方法论与数值公式仍放在 `..\通用\`，武器相关 bug 修复放在 `..\相关bug修复\`，不按主/副重复归档。

> ⚠️ **副武器比对/回迁通用教训（2026-09-08 电磁炮家族实证；用户 2026-09-21 再次强调）**：一把武器有**两个挂点**——**末端挂点**（`basePoint`）与**子弹挂点**（`shootPoint`），**两者及其挂点标记都不是美术素材**。副武器本体 sprite（sub37/sub52/sub1130 同源结构）的时间轴里普遍存在这两个命名挂点实例，在 FFDec 帧导出里渲染成**醒目的挂点标记**（方框加号或圆形加号，红/白/黑/透明任意配色，逐帧静止；**实机 2.5/3.4/新版均被 `SWFLoaderManager` 按名隐藏**——读坐标后 `visible=false`＋缩至 0.1，标记不代表任何版本的实机观感）。这是射点/基点等功能锚点（运行时据此计算子弹出射坐标），**不是美术本体**——看老版本帧图时勿把红色标记当成炮体配色或待机动画，回迁时也不能把它当作美术一起搬，版本间标记字形/配色差异不得作为对比差异项；2.5 与当前版的挂点矩阵逐字节相同，锚位无需重算。判定与细节见 `..\..\主武器家族\聚能轰击炮家族\特效复古任务\素材-2.5受击特效美术-20260908\武器视觉效果构成元素键-20260908.md` 的 A1/C1，以及 `电磁炮家族\电磁炮家族2.5-3.4-11.3检查审计-20260908.md` 第三节。
