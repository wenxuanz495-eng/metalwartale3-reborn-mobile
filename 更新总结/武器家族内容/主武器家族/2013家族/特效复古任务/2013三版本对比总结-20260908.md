## 四、视觉对比（证据等级 A）

### 1. 本体常态待机 + 开火特效 + 枪口火焰：**三版本一致**

`snow_lv1` 时间轴结构三版本逐帧相同：第 1 帧枪体（tx=1070）+ 两辅助圈；第 2 帧换开火动画层（tx=1070）+ 独立开火光斑 Shape（tx=0）+ StartSound；第 3 帧光斑换第二形态；第 4 帧移除。像素比对：**3.4 与 GitHub 全帧逐像素相同（diff=0）**；2.5 与后两者的全部差异（约 290 px/帧）经遮挡圈验证**全部来自辅助瞄准圈亮度**（2.5 中几乎不可见，按既定结论属非美术辅助标记），遮挡后仅剩 7 px 噪声。

**结论：枪体、开火闪光、枪口火焰三版本一致，无可回迁项。**

### 2. 子弹：**2.5 与 3.4 像素级相同；GitHub 为重制放大版**

- 2.5 与 3.4 子弹渲染 **91×43、逐像素相同**（md5 一致）——本家族子弹在 2.5→3.4 之间没有被动过。
- GitHub 子弹 **154×43**，可见弹体 88×34 → **133×36（约 1.51 倍宽）**，同为蓝白雪花光弹风格，白色炽心更强。
- 与金色琉璃（1.38 倍）、荷电粒子炮（1.3 倍）同属 11.3 时代子弹重制放大现象。

### 3. 受击特效：**2.5 与 3.4/GitHub 完全不同**

- 2.5：`sub/boom_hit_effect`（sub37.swf char1678）——**橙黄色火焰爆炸，7 帧**。
- 3.4 = GitHub：`bullet/blue_boom`（bullet.swf char92）——**蓝白色雪花/冰晶溅射，4 帧**（与"圣诞雪花炮"主题吻合；因 bullet.swf 同源，3.4 与 GitHub 此项零差异）。
- 注意：受击特效的更替发生在 **2.5→3.4 之间**，不是 11.3 重制造成；GitHub 是忠实继承 3.4。

## 六、数值行为备注

1. **弹速**：`bulletSpeed=30` 三版本一致。
2. **射速**：GitHub `attackGap=0.02`（30FPS 下 0.6 帧）远小于攻击动画时长，实际射速由动画帧数卡住；2.5 的 0.13（3.9 帧）接近动画时长。两版实际射速可能接近，**需实机验证**（证据等级 C）。
3. **后坐力**：GitHub `recoilValue=6` 是 2.5/3.4（=3）的两倍，开火震动应明显更强——配置层确认的差异（代码路径同 `ArmsAttack.as:132` startShake）。
4. **能耗**：`reduceRa` 0.5→1，每发能耗翻倍。
5. **attackType energy→boom**：2.5→3.4 的行为变更（爆炸型判定），GitHub 跟随 3.4。如需回 2.5 行为属于玩法变更，不只是视觉，需单独决策。

2. **受击特效**：2.5 橙色爆炸。资源在 sub37.swf，需按标准流程导入 sub1130.swf（先查 GitHub sub1130 是否已有 boom_hit_effect——金色琉璃案例中 energy_hit_effect 就是零成本先例）。
