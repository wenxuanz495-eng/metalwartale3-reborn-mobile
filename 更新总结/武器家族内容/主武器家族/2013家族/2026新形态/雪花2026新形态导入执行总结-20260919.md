## 四、过程教训（新增）

1. **新增 Character ID 前必须三属性全量普查**：`characterID=`（位图）+`spriteId=`（精灵）+`shapeId=`（形）。本轮 1804~1809 已被占用（只查 `characterID=` 会误判 1803 为最大），被手术终检在 xml2swf 前拦截——"判定不存在/空闲前先全量普查"的又一实例。
2. **FFDec XML 的 SymbolClass 是 `<tags>`(ID 列表) + `<names>`(名字列表)** 两个平行子元素，按序配对；拼接时跨元素正则极易错位，应按块提取后逐对断言。
3. FFDec XML 手写标签注意：同属性重复（forceWriteAsLong 写两次）会 XML 解析拒绝；无子元素标签应自闭合 `/>`，与源格式一致。
4. **本机 trace 通道失效**：SA 播放器（无论 debug/release）+ mm.cfg（%USERPROFILE% 与 %APPDATA% 均配置）均不输出 trace；**错误报告通道有效**（#2140、深度警告均有落盘）。运行时探针采用"未捕获错误落日志"的负空间验证 + 舞台文字供肉眼确认。
5. mxmlc 默认 `-use-network=true`（local-with-network），加载本地文件资源会报 #2140 沙箱冲突，探针须显式 `-use-network=false`。
6. 本仓库调试链播放器以 **HTTP URL** 方式加载影片（`launch_game.bat:95`），直连本地文件路径在当前环境下行为不稳。

7. **DefineBitsLossless2 fmt5 是预乘 ARGB**：A=0 ⇒ RGB 必须为 0，且 RGB≤A。首版按"非预乘 ARGB"编码（862 往返验证因二值 alpha 而判定不充分——二值 alpha 下预乘/非预乘字节相同，结论欠定），实机研究列表图标渲染出白色不透明底。修复=编码时预乘（本素材 alpha 全为 0/255，预乘即把 A=0 像素 RGB 置零），与源 PNG 逐像素可逆。**位图编码验证必须检查预乘不变量，不能只做自身往返。**
