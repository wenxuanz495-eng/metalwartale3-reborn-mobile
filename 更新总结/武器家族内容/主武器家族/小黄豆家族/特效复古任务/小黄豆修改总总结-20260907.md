# 小黄豆修改总总结（2.5 还原 × 11.3 保留 终版）

> 整理日期：2026-09-07
> 覆盖范围：2026-09-04 ~ 09-06 小黄豆（soya）家族全部修改工作
> 版本基准：2.5 原版参考（arms_35.xml / arms_34.swf）、11.3 原生（初始导入 ba10543）、当前 GitHub 仓库 main
> 本文是终版汇总；细节论证见文末关联文档索引。

## 一、最终形态一句话

**小黄豆 = 2.5 的攻击手感（双发连射 + 一大一小副弹 + LV1 后坐力 1.5 + LV5/6 射速 0.05）× 11.3 的受击视觉（bullet/yellow_motion）× 11.3 的数值体系（伤害倍率/武器等级/能量公式，按决策不动）。**

## 二、还原了什么（改为 2.5 版本的内容）

| # | 项目 | 改动 | 说明 |
|---|---|---|---|
| 1 | LV2~4 连发结构 | 新增 `<shootNum>2</shootNum>` | 一周期双发，射速 10→20 发/秒；严格 DPS 归一化（每发伤害自动减半，总输出不变） |
| 2 | 一大一小副弹 | 新增 `<secondBulletImg>` | LV2/LV3 → `arms/soya_lv1_bullet`，LV4 → `arms/soya_lv2_bullet`；偶数发用低等级小弹图，**只换视觉**，伤害/弹宽/受击特效与本等级相同；`tranArr=-5,5` 左右炮位交替同步恢复 |
| 3 | LV1 后坐力 | `recoilValue` 2 → **1.5** | 对齐 2.5，开火后坐位移更柔和 |
| 4 | LV5/6 射速 | `attackGap` 0.1 → **0.05** | 20 发/秒恢复 2.5 节奏；**非归一化改动**：每发 -25%、实战总输出 +50%（用户确认接受） |

注：第 1、2 项即 2026-09-04 曾做过又撤销的内容，09-06 重新落地并正式入库。

## 四、保留了什么（维持 11.3 现状、明确不改）

| 项目 | 现状 | 与 2.5 的差异 | 保留理由 |
|---|---|---|---|
| 主武器 DPS 倍率 | ×4×1.2 | 2.5 为 ×2 | 数值体系，按用户决策不动 |
| 能量公式 | `2×baseEnergy×(1+energy_max)` | 2.5 按 attackGap 推导 | 同上（小黄豆有无限能源，实际无感） |
| 武器等级 commonLevel | 6/14/29/44/55/70 | 2.5 为 3/11/26/41/55/70（+3） | 数值体系，不动 |
| XML `<hurt>` | 6.1/37/118/253/253/253 | 数值相同 | 玩家武器死数据，从不生效（敌方武器才直用） |
| `bulletVra` | 0 | 2.5 LV1 为 -1000 | 此前明确决策保留 0（子弹自转视觉） |
| `angleRange=1` | 全六级 ±0.5° 随机散布 | 2.5 为 0（精准弹道） | 11.3 原生微散布，肉眼难辨，保留 |
| 子弹资源 soya_lv1~5_bullet | 审计确认与 2.5 逐字节一致 | 无差异 | 无需改动 |
| 本体美术 soya_lv1~6 | 审计确认与 2.5 视觉一致 | 仅 moveBits 编码差异（零视觉影响） | 无需改动 |
| 材料/价格 mustItems、price | 11.3 体系 | 与 2.5 完全不同 | 养成数值，不动 |
| `specialProperty` 文案 | 无限能源 | 2.5 为"无限能量" | 同义文本 |
| LV2~4 recoilValue | 2 | 与 2.5 一致 | 本就相同 |
| LV1 `bulletLink`/`bulletMaxV` | 保留原样 | 2.5 无此字段/值不同 | 死配置（缺 index 永不触发 / bulletMaxVa=0 使上限失效），无行为差异 |

## 六、数值后果备忘

- **连发（LV2~4）**：`shootNum` 在伤害公式分母，每发精确减半、射速翻倍，实战 DPS 与面板 DPS 均不变——纯手感/视觉恢复。
- **射速（LV5/6）**：`attackGap` 走 `(gap+0.1)` 折算，非归一化——每发 -25%、总量 +50%。若将来要收回这 50%，改 `attackGap` 回 0.1 或加 `reduceRa≈1.3333`（后者保持 20 发/秒但总量 +100%）。
- **连带影响**：罗杰中尉等敌方玩家车的 armsArr 使用 soya_lv2/3/4，同步获得双发与射速变化（伤害同被归一化/放大，强度比例不变，弹幕观感变密）。
- 通用规则详见《伤害与等级数值系统总结-20260906.md》第八节（shootNum 归一化 / attackGap 非归一化 / reduceRa 补偿开关）。

## 七、审计结论（本次工作的副产物）

1. **美术层面 2.5 与当前完全一致**：全部本体与子弹符号经"去 Character ID 规范化闭包哈希 + 内嵌位图像素级 MD5"比对，唯一差异是 `moveBits` 边缘编码位宽（11.3 重编译产物，画面零影响）。
2. **死配置清单**：LV1 `bulletLink=subArms/missile_lv1`（缺 index 属性永不触发）、`bulletMaxV=40`（bulletMaxVa=0 时失效）、XML `hurt` 多值设计（代码只读 [0]）。
3. **方法论教训**：跨 SWF 比较不可按 Character ID 配对；哈希不同 ≠ 视觉不同，DIFF 只应触发人工复核。
