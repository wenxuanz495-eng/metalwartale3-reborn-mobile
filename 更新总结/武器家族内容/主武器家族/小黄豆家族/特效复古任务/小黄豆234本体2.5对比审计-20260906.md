## 四、审计方法论教训（重要，避免重蹈覆辙）

1. **跨文件比较绝不能按 Character ID 作 key 配对**。本次中途一次对比按 ID 为 key，
   得出"6/6 形状全部不同"的完全误报（616 与 1559 永远对不上）。正确做法：
   递归展开依赖闭包、剥离全部 ID 类属性后按内容对比（或渲染像素对比）。
2. **字节级不同 ≠ 视觉不同**。moveBits 编码差异让哈希不同，但画面完全一样。
   哈希 DIFF 只应触发人工复核，不应直接触发迁移。
3. 两份 SWF 必须用**同一版本 FFDec** 导出再比（本次同为 21.1.1，格式可比）。
