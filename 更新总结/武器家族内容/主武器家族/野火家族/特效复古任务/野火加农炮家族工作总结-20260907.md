### 2. 核心分析结论

| 项 | 结论 |
|---|---|
| 弹道速度 | 两版同为 `bulletSpeed=25`，代码无 cannon 特判——**当前速度就是 2.5 的** |
| 开火特效/武器本体/开火音效 | **像素级/字节级完全一致，无需迁移**（四形态本体、12 张火焰帧、音效 504↔1387 全部零差异） |
| 受击特效 | 2.5 用 `sub/boom_hit_effect`（sub37 #1678，**6 变体**完整爆炸演进）；GitHub 用 `bullet/red_boom`（bullet.swf #110，3 变体）；sub1130 残留同源**精简版**（#1454，仅 3 变体） |
| 子弹本体 | 2.5 短焰弹 90×32（#497）；GitHub 长条拉丝弹 198×37（#1380，11.3 改动） |
| 运行时解析 | `BulletBody.as` 随机后缀只作用于 `motion_hit_effect`；`boom_hit_effect` 按原名解析，切配置即可生效 |
