3. **像素级验收（核心）**：渲染新 f2/f3 与 2.5 f2/f3 比对——
   - 最佳整数对齐 **(0,0)**；差异 **314 像素，全部位于两个挂点标记框内**（末端挂点/子弹挂点，运行时被 `SWFLoaderManager` 隐藏的功能锚点），**非标记区 0 差异**；回迁前同项为 2831 像素差异（非标记区 2033）。

4. **零回归抽查**：snow_lv3(#1814)、magneticTrack_lv1(#582)、edge_lv1(#833) 精灵逐帧 **0 像素差异**。

## 五、经验沉淀（供后续家族参考）

1. **回迁前先全包扫描"现成等价资产"**：本次枪口特效位图在 GH 包内与 2.5 **逐字节相同**（#830 = 2.5 #30），且已存在独立形状 #831 —— 零新增资源即完成回迁；"同名≠同物"的反面同样成立："不同 ID≠不同物"，必须做哈希/像素比对。
2. **同包内已有同款手法的先例可直接套用**：edge_lv1（#832/#831）与 2.5 的（#83/#31）结构完全同构，本次按边例范式实现，风险最低。
3. **ADD 叠层的绝对位置换算公式**：`目标摆放 = 2.5 绝对位置 − 复用形状的内部矩阵平移`；绝对位置可与当前版烘焙坐标交叉验证（本次逐值一致）。
4. **移除内容会改变精灵边界** → FFDec 导出画布锚点随之微移，逐像素对比需以"非挂点区 0 差异"为准，不要把导出的亚像素伪影误判为改动。
5. **shell 转义坑**：manifest 等含反斜杠的内容不要经 heredoc 写入（`\a` 会被解释为 BEL 损坏清单行），用文件工具直接写。
