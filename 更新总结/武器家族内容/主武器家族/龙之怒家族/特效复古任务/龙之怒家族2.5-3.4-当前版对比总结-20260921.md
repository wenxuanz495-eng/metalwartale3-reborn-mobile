## 三、按用户四项对比清单

### ① 射速 / 子弹分散 / 子弹速度

- **射速**：`attackGap` 2.5=3.4=`0.13`，GH=`0.1`（攻击间隔缩短）；`attackDelay` 三方均 `0`。
  ⚠️ 面板值≠实战值——GH 侧实际发射间隔须实机计时（火神炮面板 14.9/实战 7.5 先例）。
- **子弹分散**：`bulletNum=1`，三方配置均无 `angleRange`/`tranArr` 等散射参数 → **无散射，三方一致**。
- **子弹速度**：`bulletSpeed=25`，三方一致。
- **关联动态参数**：`recoilValue` 2.5=3.4=`6` → GH=`10`（后坐力加大）。

### ② 子弹贴图 / 受击特效

- **子弹**：字段同为 `arms/dragonHead_lv1_bullet`；逐帧渲染 **三方 0.00% 像素全等**（画布 70×40，1 帧）。
- **受击**：字段同为 `sub/cutter_hit_effect`，但**同名不同物**：

| 版本 | Character ID | 帧数 | 画面 | 画布 |
|---|---:|---:|---|---|
| 2.5 | sub37 #1617 | 7（六态+清理帧） | **白色细线切割**（细线由小到大展开） | 173×13 |
| 3.4 | sub52 #1876 | 7（三态×2+清理帧） | **橙色宽线辉光** | 221×25 |
| GH | sub1130 #1509 | 7（三态×2+清理帧） | 橙色宽线辉光 | 221×25 |

  3.4 与 GH 的 `cutter_hit_effect` **逐帧 0.00% 全等**；2.5 与二者为不同美术（细线 vs 宽线）。
- **回迁成本提示**：GH 侧该导出被大范围共用——敌方配置 `xmlClass8` **415 处**、`xmlClass9` 5 处、`xmlClass7` 23 处，主武器配置 2 处（龙之怒 + 战神之刃 `edge`）→ **严禁原位替换**，须走"新建独立精灵 + 死名改绑"（先例：高周波切割炮家族 新建精灵 1985 + `cut_effect` 改绑）。
- **受击音效**（挂在受击特效时间轴内的 StartSound）：2.5 `sub37#1608` = 3.4 `sub52#1871`（MP3 字节级一致，SHA-256 `d6b141bb…`）；**GH `sub1130#1504` 与二者不同**（SHA-256 `c4d2a9db…`）。解码波形复核：三方同为 11025Hz/16bit/单声道/5279 采样，时长与分段响度一致、无时间偏移，波形相关系数 0.96（差异集中在低电平段的编码噪声）——**判定为同一音效的重新编码版本，听感无实质差异，但数据层面 2.5=3.4≠GH**。因挂在共用精灵上，GH 该音效同为敌方等 445+ 处共用。

### ③ 待机 / 开火状态与枪口火焰

- **待机（f1/f4）**：本体形状 2.5#82 = 3.4#331 = GH#857 **0.00% 像素全等**（101×35）。
  2.5 精灵内本体放置于 (60,-140)、3.4/GH 为 (0,0)——系内部注册差异，**净渲染一致**（渲染帧除下述挂点标记外逐像素全等）。
- **开火（f2/f3）**：帧结构三方一致（f1 待机 → f2 开火+开火音 → f3 持续 → f4 移除开火层回待机）；差异在"**整枪变亮**"的实现方式：

| 版本 | 开火表现构成 | 实测整枪亮度倍率（f2/f1，不透明像素全量） |
|---|---|---|
| 2.5 | 本体 + 独立枪口特效形状 #31（51×38，置于 (2033,297)）+ **ADD 混合层**（blendMode=8，精灵 #83 = 本体同图叠加） | **×2.00（精确，中位 2.000，n=2277）** |
| 3.4 | 本体 + **开火态整枪贴图** #333（125×41，含枪口火焰烘焙） | ×1.58（中位，非均匀，个别像素 0.88） |
| GH | 同 3.4（#859），**逐像素全等** | ×1.58（同上） |

  净观感差异：**开火瞬间 2.5 的整枪发光明显更强**（同图 ADD 叠加 = 精确双倍）；3.4 与 GH 完全一致。
- **枪口火焰（辉光球）**：三方外观一致——同位置、同范围的粉白辉光球；2.5 为独立形状 #31，3.4/GH 烘焙在开火整枪贴图内。剔除挂点标记后差异仅 alpha 1~2/255 的抗锯齿噪声。
- **挂点标记（末端挂点标记 + 子弹挂点标记）**：字形配色不同（2.5 暗红实心圆 vs 3.4/GH 白色圆环）——**运行时被 `SWFLoaderManager` 按名隐藏的功能锚点，非美术差异，不计入回迁对象**（通用教训）。

### ④ 新增形态与中间版本

- 三方均为**单形态**（只有"龙之怒"一级）：无新增形态、无等级错位，本武器不涉及 3.4 式基础 ID 占用问题。
- **3.4 在本武器上不是"中间态"**：除配置层 6 项早期变动外，3.4 与 GH 的美术资源（本体/开火/子弹/烟雾/受击/开火音）**全部 0 差异**；本武器的全部美术差异集中在 **2.5 ↔（3.4=GH）** 之间。
