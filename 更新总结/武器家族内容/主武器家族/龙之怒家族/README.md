## 三方核心结论（摘要，详情见对比总结）

1. **本体待机美术三方全等**（形状 82=331=857 逐像素 0.00%）；挂点标记配色差异为运行时隐藏的功能锚点，**不计入回迁对象**。
2. **开火整枪发光差异（已回迁）**：2.5 = 本体 + 独立枪口特效 + **ADD 同图叠加（精确 ×2.00）**；原 3.4/GH = 开火态整枪烘焙贴图（×1.58，非均匀）。**2026-09-21 已按 2.5 回迁**（复用 GH 内现成 #831/#830 + 新增 ADD 副本 #1815；验收=非挂点区 0 差异），`arms1100=1156A564…` 待实机。
3. **枪口火焰辉光球三方外观一致**（2.5 独立形状 / 3.4·GH 烘焙；剔除挂点标记后仅 alpha 1~2/255 噪声）。
4. **子弹、拖尾烟雾三方逐像素全等**（0.00%）；**开火音效三方字节级一致**（`19a3e27f…`）。
5. **受击 `cutter_hit_effect` 同名不同物**：2.5 = 白色细线切割（六态，173×13）；3.4 = GH = 橙色宽线辉光（三态，221×25，逐帧 0.00%）。GH 侧该导出被敌方 415+ 处共用（xmlClass8），回迁必须**死名改绑**（先例：高周波切割炮 1985 + `cut_effect`）。其内嵌**受击音效**：2.5=3.4 字节一致，GH 为重编码版（波形 corr 0.96、同时长同响度 → 听感无实质差异）。
6. **3.4 不是本武器的"中间态"**：除配置 6 项早期变动外，3.4 与 GH 美术全等；全部美术差异集中在 **2.5 ↔（3.4=GH）**。

## 注意事项

- 本家族为**单形态**，不涉及 3.4 式基础 ID 占用与形态映射表问题。
- 面板值≠实战值：`attackGap` 改动后的实际发射间隔须实机计时（通用教训）。
- 受击特效为公共资源，**严禁原位替换**；引用范围与死名改绑先例见对比总结第二节。
- **挂点提醒（见页首重点提醒）**：一把武器有**末端挂点**（`basePoint`）与**子弹挂点**（`shootPoint`）两个挂点，**两者及其挂点标记都不是美术素材**，不得作为对比差异项或回迁对象（用户强调）。
