## 分类边界

- **主武器家族**（本目录）：战车主炮体系，配置在主武器 XML（`decompiled\embedded-xml-assets\2_EmbedXml_xmlClass3_EmbedXml_xmlClass3.bin` 的 `<arms>` 节点），资源在 `arms1100.swf`（本体/子弹/烟雾）＋ `bullet.swf`（子弹/受击）＋ `sub1130.swf`（公共受击特效）。
- **副武器家族**（`..\副武器家族\`）：浮游战机、火箭/导弹等 subArms 体系，配置在 `6_EmbedXml_xmlClass7_...bin`，资源以 `sub1130.swf` 为主。
- 跨主/副的代码机制、方法论与数值公式放在 `..\通用\`，武器相关 bug 修复放在 `..\相关bug修复\`，不按主/副重复归档。

## 主武器比对/回迁注意事项

- ⚠️ **挂点通用教训**（与副武器一致，电磁炮家族实证；用户 2026-09-21 再次强调）：一把武器有**两个挂点**——**末端挂点**（`basePoint`）与**子弹挂点**（`shootPoint`），**两者及其挂点标记（⊕ 圆形/方框加号，任意配色）都不是美术素材**：只是功能锚点，运行时被 `SWFLoaderManager` 按名隐藏，游戏画面里看不到；版本间标记差异不构成美术差异、不得作为对比差异项或回迁对象。详见 `聚能轰击炮家族\特效复古任务\素材-2.5受击特效美术-20260908\武器视觉效果构成元素键-20260908.md`。
- **面板值≠实际值**：射速经 `ArmsAttack` 状态机与帧累积器（火神炮案例面板 14.9 发/秒、实战 7.5）；能量上限有运行时统一 2 倍换算（98→196）＋家族特判（火神炮槽位公式＋芯片拦截）。见 `..\通用\武器数值公式审计总结.md`。
- **公共受击特效共用**：`sub/motion_hit_effect_1~4` 有运行时随机后缀且被多家族＋敌方共用；`chipped_hit_effect` 被五家族共用——均**严禁原位替换**，回迁走死名改绑（聚能轰击炮→`bullet/blueness_energy` 先例）。基准帧图取 `..\2.5受击特效提取-20260909（文件夹）`。
- **资源三处同步**：改 `swf\` 后必须同步 `build\swf\` 与 `runtime\swf\` 并更新 manifest，否则游戏读旧资源。

## 归档规则

一个家族一个文件夹（`<家族名>\`）；家族工作展开时建家族档案 `README.md`（仿 `..\..\副武器家族\多米诺家族（质子撞击炮）\README.md`：基本信息 / 状态 / 预检与差异 / 符号 ID 速查 / 注意事项 / 文档索引）；总结命名 `主题-YYYYMMDD.md`，必备四段（目标 / 实际修改 / 构建与验证 / 待实机确认项）；移除资源留 `备份-移除的孤儿资源-YYYYMMDD\`；归档后同步更新本表一行状态与 `..\各家族变更档案.md` 对应小节。
