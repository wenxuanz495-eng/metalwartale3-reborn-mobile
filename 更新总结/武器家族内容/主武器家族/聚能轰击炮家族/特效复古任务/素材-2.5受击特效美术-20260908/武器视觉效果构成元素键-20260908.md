# 武器视觉效果构成元素键

> 整理日期：2026-09-08
> 定位：梳理一把武器的"视觉效果"由哪些元素构成、各受什么驱动、资产在哪、改哪一字段。适用于主武器体系（arms1100 + 主武器 XML），副武器体系（subArms/sub1130）结构同源。
> 来源：聚能轰击炮/火神炮/闪电炮/荷电粒子炮/等离子炮/相转移炮/微波炮/2013 等家族的对比与回迁实战结论（证据见各家族目录）。

---

## 一、构成元素总键（核对补全版）

### A. 美术资产类（SWF 内的时间轴/位图，改这些=改"长相"）

| 键 | 元素 | 驱动字段 | 资产位置 | 说明与已知机制 |
|---|---|---|---|---|
| A1 | **武器本体**（待机+开火时间轴） | `imgLabel` | arms1100.swf，导出名如 `amplitude_lv1` | 典型 4 帧结构：f1 待机 → f2 换开火本体（+光效层） → f3 光效移除 → f4 回待机；帧数可因家族而异（微波炮 6/7 帧） |
| A2 | **开火时光效 / 枪口火焰**（武器自身） | 无独立字段——**内嵌在 A1 时间轴里** | 同上 | ADD 混合层（blendMode=8）：枪口焰斑、多层蓄力光斑（低阶 1 层、高阶 1~3 层）、"发光本体"叠加（整枪发亮）；摆位由时间轴矩阵决定，静态摆位无补间 |
| A3 | **子弹本体** | `bulletImgLabel` | arms1100.swf，`arms/xxx_bullet` | 1 帧 sprite 内放 1 个位图矩形造型；多形态可共用同一张贴图（相转移）或逐级独立（聚能轰击炮回迁后） |
| A4 | **子弹拖尾烟雾** | `smokeImgLabel` | arms1100.swf，`arms/xxx_smoke` | 单造型+逐帧缩小动画（2.5 五帧 1.0→0.70）；随子弹飞行沿途播撒 |
| A5 | **受击特效** | `hitImgLabel` | 三种前缀均可：`sub/`（sub1130）、`bullet/`（bullet.swf）、`arms/` | ⚠️ 最易漏的一项。注意：`motion_hit_effect` 命名会被 BulletBody 运行时随机加后缀 `_1~_4`（四种静态变体），其他名字原样透传；受击音效随特效时间轴（f2 StartSound）一起播 |
| A6 | **待机标记 / 蓄力光斑**（待机态） | 无独立字段——内嵌在 A1 时间轴 f1 | 同上 | 炮口/炮尾的 ⊕ 小标记或光点（聚能轰击炮：2.5 暗红 #4 vs 新版白环 #20） |
| A7 | **音效**（开火/受击/拖尾） | 无独立字段——随 A1/A5 时间轴的 StartSound + 资源包 DefineSound | 各资源包 | 受击音效机制已验证（随特效 sprite）；开火音效触发路径按家族核实，勿想当然 |

### B. 动态参数类（XML 配置字段，改这些=改"节奏与观感"）

| 键 | 元素 | 字段 | 说明 |
|---|---|---|---|
| B1 | **射速** | `attackGap`（+`attackDelay`） | ⚠️ 面板值≠实际值（火神炮面板 14.9 发/秒、实战 7.5），改后必须实机计时 |
| B2 | **子弹飞行速度** | `bulletSpeed` | 同族各形态速度统一是常见维护项 |
| B3 | **后坐力** | `recoilValue` | 武器开火后移幅度；易被无关提交无意回退（传说家族 recoilValue 案例） |
| B4 | **弹道形态** | `bulletNum` / `shootNum` / `angleRange` / `tranArr` | 单发/连发/散射；连发射速另有帧累积结构（小黄豆连发恢复案例） |
| B5 | **子弹自转 / 碰撞宽 / 射程** | `bulletVra` / `bulletWidth` / `bulletLife` | bulletWidth 影响命中判定框（等离子炮按新子弹比例调整过 9~34） |
| B6 | **特殊机制（带视觉表现）** | `specialProperty` / `specialType` / `bulletLink` / `attackType` / `penetrationB` / `addArr` / `commonLevel` | 微跟踪、成长型（Level_Growth）、穿透激光线（微波炮 penetrationB）、散弹第二形态（荷电粒子 60/40 随机第二弹）等 |
| B7 | **能量系统**（间接观感：能否持续开火） | `energyUse` / `energyRate` | 运行时有统一 2 倍换算（98→196 案例），且有家族特判（火神炮槽位公式+芯片拦截） |

### C. 运行时装配层（决定"从哪出来、怎么摆"）

| 键 | 元素 | 说明 |
|---|---|---|
| C1 | **射点 / 基点** | `shootPoint` / `basePoint` 随本体类定义（如 3.4 `amplitude_lv1` 类成员），最终挂接在车体/武器装配层；相转移炮 v3 光球按"射点-(2217,200)"语义校准即为例证 |
| C2 | **资源组解析** | 字段值按 `/` 前缀 split 解析资源组（`SWFLoaderManager`）：`arms/`→arms1100、`bullet/`→bullet.swf、`sub/`→sub1130、其余→对应分包；跨组引用有大量先例 |
| C3 | **SymbolClass 注册** | AS3 SWF 追加导出名必须有 ABC 类桩，否则 Flash 丢弃；新增导出名的正路是**改绑零引用死名**（全域扫描：配置 bins+脚本+存档+动态拼接） |

## 二、原始 6 条的规范化对照

| 原始条目 | 归入 | 备注 |
|---|---|---|
| 1 武器本体 | A1 | 含待机/开火时间轴 |
| 2 子弹本体 | A3 | |
| 3 子弹拖尾烟雾 | A4 | |
| 4 武器开火时本身的光效 | A2 | 与 5 前半重叠：开火光效/枪口火焰就在本体时间轴里，不是独立资产 |
| 5 枪口、火焰、烟雾等等 | A2 + A4 | "枪口火焰/开火烟"=A2（本体时间轴内）；"拖尾烟雾"=A4（随子弹飞行），两者是不同元素勿混淆 |
| 6 飞行速度、后坐力、射速 | B1/B2/B3 | 属动态参数，决定视觉节奏而非贴图 |

**补充缺漏**：A5 受击特效（原清单最大缺漏）、A6 待机标记/蓄力光斑、A7 音效、B4 弹道形态、B5 自转/碰撞宽/射程、B6 特殊机制、B7 能量、C1~C3 装配与运行时。

## 三、排查口诀（沿用并简化）

```text
看到问题先归类：A 类找 SWF 资产，B 类找配置字段，C 类查装配与代码；
A2/A6 永远在 A1 的时间轴里，不会是独立文件；
改 A 类三处同步（swf\ = build\swf\ = runtime\swf\）+ manifest；
改 B 类注意面板≠实战；任何回迁先过"形态映射表"，像素级验证后再入库。
```
