**关键证据：**

1. **2.5 LV3 → GitHub LV5 为字节级铁证**：2.5 lv3 开火帧的发光叠加本体 `DefineSprite #171` 与 GitHub lv5 开火帧的 `#1032` **像素字节完全相同（EXACT，98×34）**。该独有资产在整个家族仅在这两个形态出现。像素相似度亦为全行最低（34.7/11.9）。
2. **2.5 LV1 → GitHub LV3**：像素相似度 37.1/14.6，为该行显著最低值；待机光斑挂载深度（d5/d7）与 2.5 lv3 系相同；本体画布比例延续。
3. **2.5 LV2 → GitHub LV4**：视觉布局一致（顶部后翼结构），但 1 首位被 lv3 占用、3 首位被 lv5 占用，按家族递进排除为 LV4；结构上 GH lv4 比 2.5 lv2 多两层光斑（3.4 给新形态增强所致）。**此条为 B+，待你确认后方可视为定论。**
4. **3.4 与 GitHub 资源逐帧字节级一致**：lv1~lv5 本体、5 发子弹、2 烟雾、受击特效全部 EXACT；GitHub 仅新增 lv6 本体（127×44，lv5 红黑换色；f4 与 f1 渲染相同）与 lv6_bullet（与 lv5_bullet EXACT 同图）。
5. 与请求人所给提示的差异：*2.5 异端审判 → "LV4 最终归宿"*——名称"最终归宿"正确，**层级实为 LV3**（LV4 是天启骑士）。

### ③ 待机/开火状态、枪口火焰与蓝色蓄力光斑

三版本本体时间轴均为 4 帧，结构同构：**f1 待机（本体 + 2 个 ⊕ 标记光点）→ f2 开火（换开火本体 + 蓝色 ADD 光斑层）→ f3 光斑移除 → f4 回待机本体**。

**待机 ⊕ 标记**（炮口/炮尾各一）：

| | 字符 | 规格 | 观感 |
|---|---|---|---|
| 2.5 | #4 | 19×19 | 暗红十字环 |
| 3.4/GitHub | #20 | 19×19 | 白环十字（与 2.5 像素差 41%） |

**蓝色蓄力/枪口光斑**（ADD 混合，blend=8）：

| 版本-形态 | 光斑数 | 字符 | 位置与缩放（矩阵） |
|---|---|---|---|
| 2.5 lv1 / lv2 | 1 | #176（37×32 青蓝光团） | d7 (397,462) 原尺寸 |
| 2.5 lv3 | 3 + **发光本体** | #176 ×3 + #171 blend8 | d9(1.77×1, 1537,592)、d11(1.77×0.72, 657,620)、d13(0.77×0.72, 664,140) |
| GH lv1 | 1 | #1025 | d7 (377,282) |
| GH lv2 | 1 | #1025 | d7 (397,262) |
| GH lv3 | 1 | #1025 | d3 (517,362) |
| GH lv4 | 3 | #1025 ×3 | d7(1.77×1, 1464,480)、d9(1.77×0.72, 557,480)、d11(0.77×0.72, 524,100) |
| GH lv5 | 3 + **发光本体** | #1025 ×3 + #1032 blend8 | d8(1524,460)、d10(617,500)、d12(584,120) |
| GH lv6 | 3 | #1025 ×3 | d7(1524,460)、d9(617,500)、d11(584,120) |

要点：

1. **枪口/蓄力蓝光斑字符三版本同一资产**：2.5 `#176` == 3.4 `#482` == GitHub `#1025`（37×32，两两字节级 EXACT）。蓝色光斑的"美术"没变，变的是**层数、位置矩阵**。GitHub lv1/lv2 新形态的开火光斑与 3.4 完全一致：同为单层 ADD（blend=8）、d7、原尺寸，坐标逐 twip 相同（lv1 在 377,282；lv2 在 397,262），仅字符 ID 因 SWF 重排不同（3.4 #482 → GH #1025）。
2. 2.5 lv3 的三层光斑排布（缩放 1.77/1.77×0.72/0.77×0.72）被 3.4 完整继承到 lv4/lv5/lv6，仅平移量微调（新美术略缩小所致，约 70~140 twip 级偏移）。
3. **发光本体叠加**（开火帧本体以 ADD 混合二次叠加，产生"整枪发亮"观感）：2.5 lv3 与 GH lv5 各有一份，且两者字节级相同（#171==#1032）——这是映射表的铁证之一。GH lv4/lv6 没有该层；GH lv5 当前在正式仓库中 blend=8（保持发亮）。注意：2026-08-27 测试包 `amplitude-restore` 曾把该层 blend 改为 Normal（`fix_lv5_transparency.py`），**该修改未进入正式仓库**。
4. 光斑在时间轴内为**静态摆位**（f2 放置、f3 移除，无逐帧位移动画）；游戏内的"光斑移动感"来自多层不同缩放/位置的组合与武器开火后坐表现，而非时间轴补间。
5. 2.5 lv1/lv2 枪口光斑深度为 d7、GH lv3 为 d3、GH lv1/lv2 为 d7——同构但深度分配随形态重排。
6. **开火枪口火焰按映射形态的部署对比**（补充追查，2026-09-08）：
   - 火焰资产三版同源同图（见要点 1），颜色形状无差别，差别全在**数量与摆位**；
   - 2.5 lv1（heir=GH lv3）：两版都是**枪口单点火焰**，位置随新炮体炮口移动（2.5 (397,462)/d7 → GH (517,362)/d3）；
   - 2.5 lv2（heir=GH lv4）：2.5 是**单点火焰**，GH lv4 增至**三层光斑**（新增，非 2.5 部署延续）；
   - 2.5 lv3（heir=GH lv5）：两版都是**三层光斑 + ADD 发光本体**的"全炮点燃"，位置微移（如主焰斑 (1537,592)→(1524,460)）；
   - "全炮点燃"在 2.5 仅最高级 lv3 拥有；新版下放给 lv4/lv5/lv6 三个形态；
   - GH lv1/lv2（新形态）为枪口单点火焰，与 3.4 逐 twip 一致（见要点 1 补充）。
   - 证据图：`聚能轰击炮开火枪口火焰对比图-20260908.png`（九格 f2 开火帧 2 倍放大）。
