错位为 **~1px 量级的美术放置偏差**，2.5 与 GitHub 都存在（细线框放置矩阵两版逐位一致），正常游玩不可见、逐帧放大才可察觉。

**细线方框的构成**（非代码生成）：sprite #1117 内矢量形状 #1116（11×11 空心方，白色细线）→ 放置矩阵（近零缩放+90° 映射）→ blendMode=ADD → BLUR+3×GLOW 滤镜（淡青白 230,255,255 / 粉紫 255,153,255 / 品红 255,0,255）。紫色观感全部来自滤镜颜色链。点亮版本体为**位图填充**（patternTransform 恒等，内嵌 PNG 像素=形状坐标 1:1），菱形位置可直接从位图连通域精确读出。
