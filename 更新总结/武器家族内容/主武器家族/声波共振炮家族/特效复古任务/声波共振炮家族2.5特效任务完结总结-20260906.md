## 三、保留的技术事实（供后续任何 wave 相关任务引用）

1. wave 四级本体闭包各 9 个 Character、四级同构；GitHub 侧差异仅 3 处/级：音效 Character（898，跨家族共享）、开火闪光描边色（DefineShape4 LINESTYLE2）、一处 moveBits 编码差（视觉等价）。
2. **音效 898 是共享资源**，同时被 phaseTransfer（风暴/雷霆/苍穹/碎空/位面/位面MK2）与 microwave（回音/末日回响/潮信/最后轻语/浩劫呼唤）全部 11 个形态引用；任何原地替换都会波及这些家族。
3. `sub/energy_hit_effect` 资源（sub1130 Character 1462）与 2.5 sub37（Character 1692）内容逐标签一致，GitHub 中由 `induction_1`（感应炮直线）使用；将来若想恢复蓝色受击，只需改 wave 四形态的 hitImgLabel 配置，零资源导入。
4. `green_energy`（bullet.swf Character 84）当前在 GitHub 配置中仅 wave 四形态使用。
5. 3.4 中间版本：wave hitImgLabel 已是 `bullet/green_energy`，attackGap=0.1；GitHub 的受击特效与射速方向均沿袭 3.4/11.3 一脉。

## 四、验证方法备注

- 资源比对：FFDec swf2xml → SymbolClass 定位 → 递归依赖闭包 → 仅 ID 属性归一化 → 逐标签 diff（不可做全数字归一化，否则会漏报颜色差异——本轮已踩过并修正）。
- 音效比对：DefineSoundTag 的 soundData 为 hex，需注意其定义属性是 `soundId` 而非 `characterID`；MP3 头含 4 字节 seek 信息，可直接 ffmpeg 解码后用 numpy 做对齐、RMS 与频谱相关分析。
- 位图颜色：FFDec `-export image` 按 Character ID 命名输出 PNG，PIL 采样主色（`-selectclass` 对 image 导出不生效，需按 ID 过滤）。
