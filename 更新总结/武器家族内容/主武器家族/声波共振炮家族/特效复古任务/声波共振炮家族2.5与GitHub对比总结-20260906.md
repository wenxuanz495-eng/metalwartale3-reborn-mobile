### 本体：四级全部不同，且差异同构（每级同样 3 处）

每级闭包均为 9 个 Character，其中仅 3 个存在差异：

1. **内嵌音效（DefineSoundTag）**：GitHub 四级共用音效 Character `898`；2.5 四级共用 Character `126`。**解码波形比对（2026-09-06 补充）：两者实为同一个声音**——同为 MP3 22.05kHz 单声道，解码后均为 626.9ms，响度包络一致（起振→0.2~0.3s 峰值→衰减），峰值 25117 vs 25121、整体 RMS 4571.8 vs 4562.3、频谱相关系数 0.998。唯一差异集中在起始约 0.1~0.2s 的起振段（该窗口 RMS 差约 5%，2.5 起音略"软"），0.2s 之后各窗口差异 0~1.3%。**听觉上基本无法分辨**（与用户试听结果一致）。
2. **描边色（DefineShape4Tag 内 LINESTYLE2）**：GitHub 为白色不透明 `RGBA(255,255,255,255)`；2.5 为半透明黑 `RGBA(0,0,0,128)`。
3. **形状编码差异（DefineShape2Tag 内 StyleChangeRecord）**：`moveBits="0"` vs `"1"`，但 moveDeltaX/Y 均为 0，视觉等价，**不算实际差异**。

其余 6 个 Character（根 Sprite 时间轴 frameCount=4、其余形状、位图等）内容一致。

### 受击特效：画面确实不同（GitHub 绿色 vs 2.5 蓝白），但 2.5 资源本体已在仓库内

**画面差异（用户观察正确，位图像素证据）**：

| 资源 | 所在文件 | 位图主色（像素采样） | 观感 |
|---|---|---|---|
| `bullet/green_energy`（GitHub wave 四形态现用） | GitHub `bullet.swf` Character 84，闭包含 Lossless 位图 77/79/81 | `(10,255,126)`、`(9,255,153)` 鲜绿 | **绿色受击** |
| `sub/energy_hit_effect`（2.5 wave 四形态使用） | 2.5 `sub37.swf` Character 1692；GitHub `sub1130.swf` Character 1462 | 白蓝辉光，主蓝 `(99,180,234)`，其余近白 `(240,255,255)` | **蓝色受击** |

`energy_hit_effect` 闭包 14 个 Character（6 帧 Sprite + 6 张 JPEG3 位图 + 1 音效），两版文件中的内容**逐标签一致**（ID 归一化后相同，且 Sprite 内无 ColorTransform 染色，颜色即位图本色）。

**公共特效归属**：`energy_hit_effect` 在 2.5 中被 传说(laserPulse)、须佐系(charged)、回音/潮信(microwave)、金色琉璃(lightKnife)、好好学习(schoolArms)、感应炮直线(induction_1)、微波炮-激光(microwave_1) 等家族共用；在 GitHub 中该资源仍被 `induction_1`（感应炮直线）引用——所以资源还在 sub1130 内且与 2.5 一致，但 wave 已被改走 `green_energy`（GitHub 中 green_energy 目前仅 wave 四形态使用）。

**结论**：恢复 2.5 蓝色受击特效只需把 wave 四形态的 `hitImgLabel` 从 `bullet/green_energy` 改回 `sub/energy_hit_effect`，**无需导入任何资源**；改回后 wave 将与感应炮直线共用同一蓝色公共受击特效，与 2.5 的公共特效归属关系一致。

## 四、音效共享关系（重要，影响将来任何恢复方案）

GitHub 音效 `898` 是**跨家族共享资源**，同时被以下导出的闭包引用：

```text
wave_lv1~lv4（声波共振炮）
phaseTransfer_lv1~lv6（风暴/雷霆/苍穹/碎空/位面/位面MK2）
microwave_lv1~lv5（回音/末日回响/潮信/最后轻语/浩劫呼唤）
```

2.5 侧音效 `126` 同样被 phaseTransfer 家族等共享。因此该音效差异是**全局性的能量武器本体音效差异**，不是声波共振炮专属：

- 若将来恢复 2.5 音效且采用"原地覆盖 898"方式，会同时改变碎空/位面系和回音/潮信系的音效；
- 若只想改声波炮，必须为 wave 闭包单独导入 2.5 音效副本（新 ID 重映射）；
- 描边色 Character 与音效不同，是否被其他家族共用未逐个排查（本次仅确认 wave 闭包内内容差异）。
