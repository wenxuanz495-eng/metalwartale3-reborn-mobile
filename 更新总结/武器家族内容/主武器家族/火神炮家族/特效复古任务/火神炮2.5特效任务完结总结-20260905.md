## 一、任务过程与结论

### 1. 全面对比（已完成，A/B 级证据）

对比 2.5 原版（`arms_35.xml` + `arms_34.swf`）与 GitHub 版（`embedded-xml-assets\2_EmbedXml_xmlClass3` + `swf\arms1100.swf`），详见《2.5与GitHub版本火神炮对比-20260905.md》。核心结论：

- **本体（lv1–lv4）字节级同源**：28 个相关 Shape 归一化逐字节一致，14 张位图像素哈希一致，开火音效字节一致，时间轴结构一致。枪身闪光/光效层两版均存在，**不存在"被删除的 2.5 特效"**。
- **枪口点被移动过**：GitHub 相对 2.5 前移 +220～+420 twips（11.3 系改动）。
- **子弹美术已换源**：2.5 三张独立 Lossless2 位图随等级增大；GitHub 共用一张 JPEG3 细长弹 + 统一 0.667 缩放。
- **配置数值差异**（后坐力、散布角、获取等级、材料、价格、lv4 名称）属于离线版刻意调整，不属于特效范畴。
- **受击特效不同**：2.5 用 `sub/motion_hit_effect`（与小黄豆共用的公共特效），GitHub 用 `bullet/red_motion`。

### 3. 最终决策（2026-09-05 确认）

经评估，**以下内容维持现状，不做修改**：

- 子弹视觉：保留 GitHub 现行统一细长弹 + 2/3 缩放，不回迁 2.5 的分级变大子弹；
- 受击特效：保留 `bullet/red_motion`，不恢复 2.5 的 `sub/motion_hit_effect`；
- 枪身闪光/本体特效：两版本就同源，无需回迁；枪口点保持本次 +200 twips 的前移。

理由：本体特效已证明无差异，子弹与受击特效的差异属离线版既定视觉方案，回迁收益低且需大量 ID 重映射工作。
