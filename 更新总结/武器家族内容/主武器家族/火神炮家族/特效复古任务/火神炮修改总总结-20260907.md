> 整理日期：2026-09-07
> 覆盖范围：2026-09-05 ~ 09-07 火神炮（fireFairy）家族对比审计、名称恢复与枪口点修复全部工作
> 版本基准：2.5 原版参考（arms_35.xml / arms_34.swf）、11.3 原型（GitHub 仓库初始基线）、当前 GitHub 仓库 main

## 一、最终形态一句话

**火神炮 = 2.5 的本体（字节级同源，无任何可回迁差异）× 11.3 的子弹与受击视觉（细长弹 + red_motion，按决策保留）× 两项定点修复（LV4 名称恢复 2.5 原文 + 四形态枪口点前移 200 twips）。**

火神炮是全部家族中唯一得出"2.5 与当前版本本体完全同源、不存在被删除特效"结论的家族——本轮工作重心因此从"回迁"转为"审计确认 + 定点修复"。

## 三、决策不改什么（2.5 差异保留清单）

| 项目 | 当前（11.3）终态 | 与 2.5 的差异 | 保留理由 |
|---|---|---|---|
| 子弹视觉 | 四形态统一 `arms/fireFairy_bullet`，共用 1 张 JPEG3 细长弹（24×116）+ 统一 0.667 缩放 | 2.5 为三张独立 Lossless2 位图（33×19 / 35×20 / 39×22）随等级变大 | 离线版既定视觉方案；此前已刻意统一并缩小；回迁需三张位图导入 + 分级配置恢复，收益低 |
| 受击特效 | `bullet/red_motion` | 2.5 为 `sub/motion_hit_effect`（与小黄豆共用的公共特效） | 同上；注意小黄豆家族最终也决策保留 11.3 原生 yellow_motion，两家族口径一致 |
| 本体特效（枪身闪光/开火光效层） | 与 2.5 字节级一致 | **无差异** | 无可回迁内容（详见第四节审计结论） |
| `recoilValue` | 2 / 2 / 2 / 3 | 2.5 全形态 1.1 | 离线版数值调整 |
| `angleRange` | 全形态 8 | 2.5 全形态 10 | 离线版数值调整 |

| 开火音效 | 与 2.5 字节一致（soundData 相同） | 无差异 | 无需改动 |

## 四、审计结论（本轮工作核心副产物）

1. **本体字节级同源（A 级静态证据）**：lv1~lv4 全部 28 个相关 Shape（本体 4 + 枪身闪光/光效层 24）经"去 Character ID 规范化逐字节对比"**28/28 完全一致**；14 张位图像素哈希一致；开火音效 soundData 字节一致；时间轴结构（7 帧、d1 本体 / d2 闪光 / d3 basePoint / d5 shootPoint）逐层对齐。**2.5 时代不存在被删除的枪身闪光**——若实机观感闪光变弱，方向是细长弹道遮盖（已由枪口点前移缓解）或射速帧累积器改变动画节奏，而非资源删除。
2. **唯一被移动过的本体元素是 shootPoint**：11.3 相对 2.5 前移 +220~+420 twips，属原型期刻意修改（枪身加长/弹道外扩），本轮在其上再 +200 修复压枪体问题。
3. **子弹美术已彻底换源**：与 2.5 不同源（11.3 系细长弹），"只调缩放恢复 2.5 分级变大"不可行，已按决策放弃。
4. **方法论沉淀**：FFDec XML 子标签在 `<subTags>` 下，按 Sprite 分块校验须以下一个 `DefineSpriteTag` 起点为界；`</item>` 截取会因嵌套提前截断产生假阴性；SHA-256 清单路径含 `\`，脚本写回注意转义。

## 六、数值后果备忘

- **名称**：纯文本变更，`OneArmsDefine.as` 直读 XML `<name>`，无存档兼容问题。
- **枪口点 +200**：仅子弹出生位置右移 10px，不影响伤害、速度、碰撞判定（弹宽由 `bulletWidth` 决定）；四形态出膛视觉与炮口距离增大，若实机观感"子弹离枪口太远"可回调至 +100~+150，改法同本轮。
- **连带影响**：敌方使用 fireFairy 家族武器时同样使用该 SWF 本体，枪口点变化对敌方同样生效（视觉层面，无数值影响）。

## 七、验证记录

- FFDec swf2xml → xml2swf 回读校验：四形态 shootPoint 新值全部命中；7 个导出名（lv1~4 + bullet×3）齐全；本体 frameCount=7、子弹 frameCount=1 不变；basePoint（330/310/230/220）未受影响。
- `config\build\current-resource-manifest.sha256` 同步更新；`构建.bat` 全量构建退出码 0；`build\swf`、`runtime\swf` 与源三处哈希一致；`build\game.swf` 解压验证已含"重型火神炮三连装"、旧名消失；`launch_game.bat --check sa` 通过。
- 09-07 复核：在闪电炮、荷电粒子炮等家族先后导入 arms1100 后，四形态枪口点仍为 1690/1700/1970/2270（在 HEAD 与工作区均验证通过）。
