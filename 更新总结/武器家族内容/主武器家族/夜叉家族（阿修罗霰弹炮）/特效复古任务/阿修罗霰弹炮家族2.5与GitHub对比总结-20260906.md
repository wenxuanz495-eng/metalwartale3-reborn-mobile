# 阿修罗（霰弹炮）家族 2.5 与 GitHub 全面对比报告

对比日期：2026-09-06（v2，新增射速/后坐力/子弹速度/散射方式与运行时代码对比）
对比范围：2.5 原版 ↔ 3.4 原版 ↔ GitHub 仓库当前版本（三版），覆盖配置、资源与运行时代码。
证据等级：配置与代码差异为 A 级（文件直接取证）；资源结构差异为 B 级（FFDec XML 结构 + 位图像素哈希 + 形状边界取证，未实机验证）。

| 侧 | 配置文件 | 资源文件 | 运行时代码 |

## 二、射速对比（配置 + 状态机 + 面板公式）

### 2.1 攻击状态机：代码完全一致，霰弹炮不受 GitHub 任何专用分支影响

- `ArmsAttack.shoot()`（静态发射函数）：2.5 与 GitHub 逐字一致（仅反编译器 `if(attackBody)` vs `if(Boolean(attackBody))` 写法差异）。
- `ArmsAttack.attackPan()`（状态机）：GitHub 相比 2.5 唯一新增的是火神炮专用分支 `attackPanFireFairy`（含帧累积器），其进入条件为 `d.id == "fireFairy" && d.shootNum == 1 && baba is HeroCarBody`。**霰弹炮不满足条件，走与 2.5 完全相同的原始状态机。**
- `INIT.FPS = 30`：两版文件 diff 完全一致。

### 2.2 实际射速：GitHub 更慢（齐射间隔 8 帧 → 10 帧）

状态机节奏（attackDelay=0、shootNum=1、无 shootGap 时）：start(1帧) → shoot 发射整组弹(1帧) → overing 等待 attackGap（帧量化）→ over(1帧) → 循环。

| 项 | 2.5 / 3.4 | GitHub | 差异 |
|---|---|---|---|
| `attackGap` | 0.15 s | 0.2 s | GitHub 慢 |
| 单周期实际帧数（FPS=30 推算） | 8 帧 ≈ 0.267 s | 10 帧 ≈ 0.333 s | +2 帧 |
| 齐射频率 | ≈ 3.75 次/秒 | 3 次/秒 | **-20%** |
| 每秒弹数 lv1（4弹/齐射） | ≈ 15 发/秒 | 12 发/秒 | -20% |
| 每秒弹数 lv4（7弹/齐射） | ≈ 26 发/秒 | 21 发/秒 | -20% |

推算说明：overing 状态每帧检查 `now_t >= attackGap` 后才累加，0.15×30=4.5 帧需 5 帧跨越、0.2×30=6 帧需 7 帧跨越；实际节奏以实机逐帧计数为准（此前火神炮已证明面板数与实机数可能不一致）。

### 2.3 面板射速公式：11.3 系改动

`OneArmsDefine.getShootSpeed()`：

- 2.5：`1 / (attackGap + 0.1) × shootNum × bulletNum`
- GitHub：`1 / (attackGap + 0.067) × shootNum × bulletNum`

影响武器介绍面板显示（2.5 霰弹炮面板 ≈ 4.0 次/秒，GitHub ≈ 3.7 次/秒），不影响实际开火。这是 11.3 系对固定周期开销估计值的修改，属于原版演进。

## 三、后坐力对比

- 实现完全一致：`shoot()` 末尾 `attackBody.shake.startShake(1.5, 0.2, ra - π, 0, recoilValue)`；`ShakeMotion.as` 两版 diff 完全一致。参数含义：number=1.5、时长 0.2s（6 帧）、方向与射击相反、range1=0、**range2=recoilValue 为震动幅度**。
- 配置值：2.5/3.4 全形态 `recoilValue=2`；**GitHub 全形态 `recoilValue=5`**。
- 结论：后坐力代码同源，GitHub 震动幅度是 2.5 的 2.5 倍，属离线版刻意调整。

## 四、子弹飞行速度对比

- 赋值链路两版一致：`attackEvent.v0 = d.bulletSpeed`；`bulletMaxV` 未配置时默认 = `bulletSpeed`（`OneArmsDefine.inData_byXML` 对应行两版一致）；`BulletBody` 运动逻辑 diff 仅含 GitHub 新增功能字段（穿透 `penetrationNum`、破碎等离子 `Broken_PlasmaB`），与霰弹炮无关。
- 配置值三版一致：`bulletSpeed = 25 / 25 / 25 / 20`（lv4 迦楼罗弹速更低是原版设计，历版如此）。
- `bulletVra`（自旋）：三版配置均未设置，解析行为一致（无自旋）。
- 结论：**子弹飞行速度与弹道行为三版完全相同，无差异。**

## 五、散射方式对比

- 实现完全一致（`shoot()` 多弹分支）：`bulletNum > 1` 时，`bulletNum` 发弹在 `angleRange` 内**均匀扇形分布**（第 n 发角度 = `-angleRange/2 + angleRange/(bulletNum-1)×n`），并在垂直于射向方向上按 `bulletTranslation` 线性横向展开（总展开宽度 = 2×bulletTranslation）。多弹为确定性扇形，无随机抖动（随机抖动只用于 `bulletNum==1` 分支，霰弹炮不用）。
- 配置值三版一致：

| 形态 | bulletNum | angleRange | bulletTranslation |
|---|---:|---:|---:|
| lv1 夜叉 | 4 | 10° | 3 |
| lv2 摩呼罗迦 | 5 | 12° | 5 |
| lv3 阿修罗 | 6 | 15° | 5 |
| lv4 迦楼罗 | 7 | 18° | 7 |

- 结论：**散射方式与散布范围三版完全相同，无差异。**

## 六、其余视觉元素对比（资源层）

### 6.1 本体与开火特效：三版完全同源，无任何差异

本体为 4 帧动画：第 1 帧 d1 本体 + basePoint/shootPoint；第 2 帧 d4 开火闪光 + StartSound；第 4 帧复位。逐项归一化哈希对比：

- 本体形状（d1，lv1–lv4）：三版逐字节一致。
- 开火闪光形状（d4，lv1–lv4）：归一化后逐字节一致（初报差异仅为 FFDec `moveBits` 编码位，moveDelta 均为 0,0，视觉零影响）。
- 闪光位图像素、开火音效（soundData 字节一致）、basePoint/shootPoint：三版完全一致，**无枪口点位移**（与火神炮不同）。

挂点数值（三版相同）：lv1 base(264,480)/shoot(1064,470)；lv2 (264,480)/(1224,490)；lv3 (364,510)/(1434,530)；lv4 (424,550)/(1624,550)。

## 八、对"2.5 老特效/手感回迁"的指导

1. **无可回迁的本体特效**：本体、开火闪光、音效、挂点三版完全同源。
2. **散射、弹速无需处理**：代码与配置均与 2.5 一致。
3. 可回迁项只剩三个，均为用户决策项：
   - **子弹美术**（2.5 圆头短弹 41×22 ↔ GH 加长束 79×22）：从 `arms_34.swf` 导入位图 437 + 形状 438，重映射后替换 GH sprite 1329/shape 1328。单帧、单位图依赖，低风险。
   - **射速**：`attackGap` 0.2 → 0.15（纯配置行，1 处/形态，共 4 行）。
   - **后坐力**：`recoilValue` 5 → 2（纯配置行，共 4 行）。
   - （可选）**受击特效**：配置改回 `sub/motion_hit_effect`，但 3.4 原版已自行放弃该调用（火神炮先例为保留 red_motion）。
4. 面板射速公式（0.067 vs 0.1）是 11.3 系全局改动，随射速回迁会自动联动，不建议单独改。
5. 若执行迁移，遵循《武器特效导入标准流程.md》与《火神炮修改与武器导入经验总览》第八节流程；改完配置需重跑 `构建.bat` 并同步 `build\swf`、`runtime\swf` 与哈希清单。
