## 通用（先读这里再动任何家族）

> ⚠️ **通用教训（电磁炮家族实证，所有武器适用；用户 2026-09-21 再次强调）**：一把武器有**两个挂点**——**末端挂点**（`basePoint`）与**子弹挂点**（`shootPoint`），**两者及其挂点标记（⊕ 圆形/方框加号，任意配色）都不是美术素材**：它们只是功能锚点，运行时被 `SWFLoaderManager` 按名隐藏，**游戏画面里看不到**。故版本间挂点标记的字形/配色差异**不构成美术差异**，既不能作为对比结论中的差异项，也不得作为回迁对象；逐帧静止的几何标记=挂点标记，随帧变化的才是美术。完整判定细节见 `副武器家族\README.md` 教训条目与《武器视觉效果构成元素键》。
> ⚠️ **通用教训（恶魔牙家族实证）**：蓄力段特效必须区分**蓄力指示**（小白圈脉冲→贴剑柄/圆饰）与**枪口火焰**（生长链→枪头），蓄力小圆圈极易被忽略或被顺带搬动；圆形特效定心必须用渲染像素 alpha 加权质心，1px 收口以用户实机取色为准。详见 `副武器家族\恶魔牙家族（飞刃炮）\特效复古任务\蓄力小圈与枪口火焰判别及白圈定心微调闭环-20260914.md`。
