# 修改器特殊功能改名与语义扩展（"研发无视全部条件" → 一切交互无视一切条件）

> 立项日期：2026-09-14（用户在芯片合成复制 bug 修复决策中提出）
> 状态：已立项，未实施；语义边界待定义

## 现状

修改器（`modifier.html`）特殊功能中的 `modCraftFree` 当前显示名为**"研发无视全部条件"**，写入存档后由 `GameData.modCraftFree` 生效（读档补完养成 + 研发条件放行 + 材料背包消耗豁免，机制详见 `bug 维护\芯片合成拖入不扣材料复制bug源头排查-20260914.md` 第一节）。

## 目标方向

改名为类似**"研发、购买、合成等一切交互无视一切条件"**的表述（用户原话大意，最终文案待定）。

## 待定义的语义边界（实施前必须逐项拍板）

1. **购买**：是否指商城 G币/M币 购买免费？涉及哪些商店（普通商店、精选装备、成长礼包、儿童节兑换等）？
2. **交互范围**：除研发/购买/合成外，还有哪些交互纳入（洗炼、镶嵌、拆解、公会贡献、头像解锁……）？
3. **条件豁免口径**：等级门槛、前置物品、货币不足是否全部放行，还是仅货币类？
4. 与现有其他特殊功能（无限能量、一击必杀等）的命名风格统一。

## 已完成的第一步（本次 bug 修复中落地）

- 同 bug 修复中确立了"费用豁免与物品位置转移分离"的实现红线：豁免免费，但不产生物品复制。
