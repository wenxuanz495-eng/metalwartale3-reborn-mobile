## 六、追加批次（同日：兜底层平局改随机，修复"丢怪"）

**用户反馈**：场上无优先级怪、所有怪血量一致时，有时会"丢怪"（部分怪长期无人打）。

**根因（已核实）**：兜底层血量一致的平局判定原为**确定性规则**（首次发现时刻早 → 距离近）——所有弹各自独立选择时都会命中同一个"最老"的怪，全场弹聚焦过杀同一目标，其余等血怪被无视，直到它死后全群再转向下一只。"丢怪"实为**聚焦过杀导致的分配倾斜**，非漏选。

**修复（按用户指定：平局改随机）**：`selectInductionTarget()` 重写平局分支——同层同血量时改用**蓄水池随机**（`Math.random() × tieCount < 1`，等概率抽取），每发弹独立随机 → 弹群近似均匀分布到各等血怪身上。自爆层（tier 10）保留用户指定的"生成时间早 → 距离近"规则不变。平局计数在层级/血量变化时重置。

**行为变化**：等血怪群从"逐个聚焦处决"变为"均匀火力覆盖"；有血量差时仍严格打最低血者。

## 七、追加批次（同日：平局策略改为"随机选定 + 集火到死"）

**用户纠正**：上一批的均匀分摊（蓄水池随机）会让伤害摊薄——"什么怪都杀不死"。正确设计：**全场随机选定一只 → 全弹集火到死 → 死后全群立刻转移**；有残血怪时优先补刀；优先级怪物出现时集体转向。

**实现**（`selectInductionTarget()` 第三次迭代 + 新增 `focusBody` 共享状态）：

1. 单次遍历：确定最高优先层（bestTier）与该层最低血（minLife）；层内候选按既有规则取 randBody（自爆层：生成时间早→距离近；其余层：蓄水池随机）；
2. **焦点持久化**：新增 `focusBody` 字段（BodyGroupRefresh 实例级共享）——若焦点怪仍存活、仍在最高优先层、血量仍等于 minLife，则**所有无目标弹都返回同一个 focusBody**（集火）；
3. **转移时机**：焦点死亡（不在存活列表）→ 全群同时选新焦点；出现更残血的怪（minLife 下降且焦点不在最低组）→ 集体补刀；更高优先级怪出现（bestTier 变化）→ 集体转向。三种转移对全部无目标弹同步发生——**转火可见性**：全群齐转，不再一只只散换。

**回答用户疑问**：死亡转火此前已实现（目标 hitHurtB/die 置位 → 清空 targetBody → 重分配），实测不明显是因为确定性平局下弹群瞬间锁上同一只下一目标、转移动作无观感；本批改为共享焦点后，"杀死→全群齐转"的节奏清晰可见。

### 验证

- 构建退出码 0（补丁 110）；反向导出确认 focusBody 逻辑编入（6 处引用）；
- `launch_game.bat --check sa` 通过。
- 实机验证：等血怪群应呈"逐只集火处决"节奏；残血怪出现集体补刀；Boss/自爆出现全群转向。

### 8.4 已撤销：焦点集火选择函数（最终版）

```actionscript
private var focusBody:* = null;

private function selectInductionTarget() : *
{
   var arr0:Array = this.BG.getHurt_Arr2(this.BG.enemy_arr);
   var bestTier:int = 99;
   var minLife:Number = 0;
   var randBody:* = null;
   var randTime:int = 0;
   var randDist:Number = 0;
   var randCount:int = 1;
   var focusOK:Boolean = false;
   var hero0:* = this.BG.heroCar_arr.length > 0?this.BG.heroCar_arr[0]:null;
   var now:int = getTimer();
   var n:* = undefined;
   var b1:* = null;
   var tier:int = 99;
   var life:Number = NaN;
   var t:int = 0;
   var dist:Number = 0;
   for(n in arr0)
   {
      b1 = arr0[n];
      tier = this.inductionTargetTier(b1);
      if(tier >= 99)
      {
         continue;
      }
      life = Number(b1.define.nowLife);
      if(this.spawnTimeMap[b1] == null)
      {
         this.spawnTimeMap[b1] = now;
      }
      t = int(this.spawnTimeMap[b1]);
      dist = hero0 != null?Number(Maths.Long(b1.MX - hero0.MX,b1.MY - hero0.MY)):0;
      if(tier < bestTier)
      {
         bestTier = tier;
         minLife = life;
         randBody = b1;
         randTime = t;
         randDist = dist;
         randCount = 1;
      }
      else if(tier == bestTier)
      {
         if(life < minLife)
         {
            minLife = life;
            randBody = b1;
            randTime = t;
            randDist = dist;
            randCount = 1;
         }
         else if(life == minLife)
         {
            randCount++;
            if(tier == 10)
            {
               if(t < randTime || t == randTime && dist < randDist)
               {
                  randBody = b1;
                  randTime = t;
                  randDist = dist;
               }
            }
            else if(Math.random() * randCount < 1)
            {
               randBody = b1;
               randTime = t;
               randDist = dist;
            }
         }
      }
      if(b1 == this.focusBody && tier == bestTier && life <= minLife)
      {
         focusOK = true;
      }
   }
   if(this.focusBody != null && focusOK)
   {
      return this.focusBody;
   }
   this.focusBody = randBody;
   return this.focusBody;
}
```

配套字段：`private var spawnTimeMap:Dictionary = new Dictionary(true);`（弱键，惰性注册首次发现时刻）、`private var focusBody:* = null;`
配套导入：`data.Maths`、`enemy.airLaserFort.AirLaserFortBody`、`enemy.satellite.SmallSatelliteBody`、`enemy.spider.SpiderBody`、`flash.utils.Dictionary`
