## 一、版本与架构总览

- 版本号：`Game.checkVersion()` 写死 `versionNumber = "4.0"`；文档类 `Game`（923 行），包结构与 11.3 的 `decompiled/gamefile` **同构**（`gameAll/`、`body/`、`UI/`、`net/`、`EmbedXml` 等）。

**代际结论**：4.0 与 3.4 同代（XML 配置集几乎一致，另多出 `exchangeConfig/dengjilibao/turntable`），是 11.3 的直系祖先。2.5/3.4 武器审计工具链（arms61/subArms52/enemy25 同名配置）对 4.0 基本直接适用。

## 四、GameData 字段盘点（阶段 3 修改器映射）

- **货币**：`GCoin/MCoin` 为 Number 访问器（第 1144~1181 行，后备字段是 String 防大数精度）+ **`GCoin2/MCoin2` 镜像字段同在**（第 97~103 行）——与当前 Go 修改器的 `normalizeCurrencyMirrors` 同步逻辑直接通用。
- **进度**：`levelsLock = [1,0,0,0,0]`（第 127 行）、`nowDifficult`（131）、`nowGameLevel`（133）——字段名与 11.3 一致，修改器"进度"卡片映射不变。
- **玩家**：`playerName` 默认 **"4399小战士"**（第 117 行）。
- **反作弊（重点差异）**：4.0 原版带完整作弊检测——每次读档执行 `Game.zuobiTest()`（第 280~301 行）：经验/积分比校验（level>10 时 exp > score×400 即标记）、训练等级校验（`zuobiPan`，加成>3 标记）、物品数量校验（`materialsItems.isZuobi()`）；存档字段 `isZuobi/zuobiStr`（GameData 第 175 行）；`CheatingController.checkZuobi` 默认 true。**修改器改数值必须绕过或放宽这套检测**（单机离线无排行榜，建议在离线补丁中禁用，与 11.3 离线版处理对齐——待用户确认）。
- **mod 旗标**：4.0 **没有** `mod*` 系列字段（那些是本项目在 11.3 源码上注入的）——阶段 4 若要做需从零注入。
