## 二、技术资产沉淀（本期新增的可复用能力）

1. **新导出名双注册管线**（本库首例走通）：mxmlc 编译存根类 → DoABC2 标签移植 → SymbolClass 配对追加；两条邪路的实证（SymbolClass-only=1065、手拼 ABC=1107）与探针验证法一并沉淀（详见 README 标准流程第 6/7 步）。
2. **FFDec XML↔AVM2 索引规则**：常量池子项位置=AVM2 索引（0 基，无 +1）；trait bytes 内嵌 u30 同步改写。
3. **时间轴深度规划三原则**（弹下枪上效果更高锚点最高 + 无冲突断言）与**镜像重锚法**（枪口/枪轴差平移）。
4. **像素级素材验收/对位法**：alpha 阈值分层量测（实心 128 / 可见 10）、滑窗对位、颜色吻合判定（本任务用于挂点组合弹的复原与定位）。
5. **验证工具链**：FP34 debug 探针（加载/实例化/锚点检查，结果经实例上台+用户录屏确认）、逐帧像素恒定断言、binaryData 回读。

## 三、3.0 前瞻期的口径与边界

- 版本口径：3.0 前瞻开发期的产出**直接进 main 分支**（不同于 2.x 时代按内测版打包）；玩家可见变更待 3.0 首个发行包的 `公告.txt`。
- 任务分类口径（用户定义）：**特效复古**=回迁旧版素材观感；**星座特效+新捏形态**=新建内容（画师新捏 + 星座系金色审美）。两线并行时， retro 线成果可被新建线引用（如金链 2734~2755 即复古批次产物的复用）。
- 数值口径：新建等级的成长值/附魔/合成链由用户逐级拍板（本期：Growth 30/40/50/60、subAdd 0.4~0.7、Y_num100/150/200/300）；黄金 lv1 双发（本系 lv1 单发）维持既有设计。
