## 四、字段口径与红线（手游版）

1. **哈希口径**：取包旁 `.sha256.txt`（大写哈希 + 两空格 + 文件名 + CRLF，无 BOM）；本表取前 16 位，完整值见冷备对应目录。
2. **测试包与正式版分离**（2026-09-21 用户裁定）：正式版进 `手游端\3.x.x\` 版本夹；迭代测试包进 `手游端\测试\`
   （命名 `SuperAlloy-Mobile-<版本>-测试-<主题>-YYYYMMDD-<arch>-debug.apk`），**不入版本夹、不登记为本表版本行**。
3. **无 GitHub Release（现状）**：截至 2026-09-21 手游仓 **0 Release**（端游 `v3.0.0-alpha` 有 Release）。
   手游目前走本地包/群分发；若将来发 Release，须按端游口径用**英文附件名**并以 SHA-256 与本地中文名一一对应。
4. **版本号体系**：1.0~1.2.5 为独立计数期（未对外）；自 **3.0.3** 起与端游同步，此后随端游节奏——小版本顺延 **3.0.4**、
   较明显更新 **3.1.0**、较大更新 **4.0.0**。
5. **tag 与 bug 修复的分工**：tag 只标**版本发行**；周期内的 bug 修复走 `bug 维护\` 建档，不单独挂 tag。
6. **归档联动**：新增版本行后，同步 `更新总结\README.md` 索引；若该版本有独立总结，归入对应分类目录/版本夹。
