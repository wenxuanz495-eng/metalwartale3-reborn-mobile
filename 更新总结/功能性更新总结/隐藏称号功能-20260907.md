# 隐藏称号功能（称号界面按钮改版）

> 完成日期：2026-09-07
> 工作区：`D:\superalloy\metalwartale3-reborn.git`

## 一、目标

1. 称号界面（荣誉/成就面板的"已获得称号"页）右下角的单个大"使 用"按钮，改为 2×2 四个小按钮：
   - 上排：**使用称号**、**放弃称号**
   - 下排：**隐藏称号**、**显示称号**
2. 新增"隐藏称号"功能：称号保持使用状态（称号属性仍生效），但隐藏头顶的称号/红星对外显示（含 VIP 称号黄字）。"显示称号"恢复显示。
3. 隐藏状态随存档持久化，旧存档自动兼容（默认显示）。

按钮状态逻辑：
- **使用称号**：选中已获得且非当前称号时可用（沿用原 useClick 逻辑）
- **放弃称号**：当前使用中称号非"无"时可用，置 `nowHonor = "no"`
- **隐藏称号**：`hideHonor == false` 时可用，置 true
- **显示称号**：`hideHonor == true` 时可用，置 false
- 不可用态与原按钮一致：整体 alpha 0.3 + mouseEnabled=false；"未获得称号"页四按钮整体隐藏
- "当前称号"文本在隐藏状态下显示"××（已隐藏）"

交互保障：SimpleButton 自带 hitTestState（完整 114×36 区域），悬停有增亮态，可正常点击。

## 二点五、第三版：布局越界返工 + 按钮精简（2026-09-07 深夜）

实机反馈：第二版 2×2 布局越出面板/舞台边界（放弃称号超出右边缘、隐藏/显示行掉到面板底部之外），且无法交互。

边界考证（解剖 ui1120.swf 并渲染 honor_mc=sprite661，1793×826）：
- 面板背景（char 644）在 honor_mc 空间：x 16~947，y 52~489
- 原大按钮 use_btn 可见梯形：x 714~924，y 421~464（底边 464，面板底 489）
- 结论：上一版把下排锚在"按钮底边之下"必然越界；第二列右移 124 也超出右边缘

第三版定案（用户要求：只留两个按钮，隐藏/显示合一变字）：
1. **使用称号**（黄框）：居中于原大按钮中心 (cx, cy)，尺寸 114×36——必然落在原按钮条带内
2. **隐藏/显示切换**（青框）：在使用按钮左侧（x − 124，同行同高）——该区域为面板空白带，同条带内
3. 切换按钮点击后仅变字：标题可见时显示"隐藏称号"，隐藏时显示"显示称号"；点击即切换 `hideHonor` 并刷新头顶显示
4. 放弃称号按钮取消（放弃=在列表选"无"后点使用称号）

修改文件与上一版相同（HonorUI.as/HonorData.as/EventGroup.as/构建清单），构建 SHA-256 `14F2167D29CDA18447F2A3F0003E1D3A53E5B26B06A8AEB13279820C58F510B7`，启动自检通过。

实机微调（同日）：黄框右缘轻微出界，布局改为按面板右内缘（947−14=933）右对齐固定——黄框 x 819~933，青框 x 695~809，间距 10；"当前称号"隐藏后缀由"（已隐藏）"缩短为"（隐藏）"避免文本撑出面板。构建 SHA-256 `1BD860D49EA1896879E3F891FE876A0852924D37C5978FD47223BA762F502D96`，自检通过。
