## 归档规则

1. bug 维护：排查 → 方案 → 修复 → 实机全周期写在同一份内，状态行跟踪（`已定位` → `已实施修复，待实机` → `已关闭`）。
2. 专项总结：随批写入，标题带日期；移动或重命名必须同步本索引与引用方。
3. 与端游仓 `更新总结\` 的分工：端游侧记录端游本体与两仓协作事故（如克隆符号 boot-fail、bat 行尾事故）；本仓记录手游端自身的专项与 bug。
