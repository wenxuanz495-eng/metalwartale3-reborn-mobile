# 黄金黑绳可被直接研发绕过核心获取 · 排查与修复记录

> 记录日期：2026-09-20
> 状态：**已实施修复，待实机确认**
> 现象（用户报告，3.0.0-alpha 发布后）：黄金黑绳只能够核心获得，但是现在可以直接购买升级——第一阶（未拥有）就能直接研发，第 2/3 阶升级也不应"那样"直接获得。用户裁定：界面显示"通过开合金/活动获得"之类的途径提示可以接受，但第一阶不能直接研发、后续阶不能绕过核心链直接获得。

---

## 一、复现链（代码级推演）

1. **进入研发列表**：`ArmsDataFilter.getOneList`（`ArmsDataFilter.as:30`）对未拥有的武器定义只做 `d0.index < 50` 判定即以"可研发定义"进列表——`cutter_gold` index=14 入榜（黄金恶魔牙 goldflyBlade index=9 同样入榜）。
2. **选中条目**：`ArmsResearchUI.chooseGradeArmsIcon` 未拥有分支 → `showArmsMust(0)` 渲染 lv1 研发条件。
3. **条件渲染**：`getBuySite("cutter_gold_lv1")` 自 20260917 黄金深渊战役"移出活动特判"后返回 `""` → `shop_mc` 整体隐藏（无途径提示），但研发条件区正常放行：`mustLevel=1`、`mustItems` 空、**`price=20000`**。
4. **执行研发**：`upgradeClick` → `addCoin(-20000)` → `addItems("cutter_gold_lv1")` →"你获得了一把新武器！"——20000 G币直接绕过战斗核心投放。
5. **放大器**：`HelperBuilder.as:54` 对 `getBuySite` 返回空且未拥有的武器，助手条主动推荐"可研发新武器：黄金黑绳"。

## 二、根因

**两层叠加**：

1. **数据层残留**：`cutter_gold` 五级配置由 `config_gold_lv5.py` 以"price 照抄本家"口径生成，收口终态 lv2~5 price 已清空，**lv1 残留 `price=20000`、`Jprice=48`**；金线正确形态应为 price/Mprice/Jprice 全空（对照模板 goldflyBlade 六级全空）。
2. **门控层缺口**：活动特判移除后 `getBuySite("cutter_gold_lv1")` 返回空，研发界面把它当普通可研发武器对待（条件渲染、按钮、助手推荐全链路放行）。`price` 仅在研发扣费处被读取，封死 UI 门控后数据残留即不可达。

附注：阶 2~5 无独立获得路径（等级条为纯展示、`showArmsMust` 仅由下一阶/lv0 两处调用），封死 lv1 研发即封死整线非法入口；持有 lv1 后的升阶走 `prevLabel` 原位升级链，不受影响。

## 三、修复方案与决策点

用户拍板（2026-09-20）：第一阶不能直接研发；后续阶不能绕过核心链直接获得；显示获得途径提示文本可接受。

- `getBuySite` 新增 **`"core"` 渠道**，仅匹配 `cutter_gold_lv1`（升阶视图用的 `cutter_gold_lv2+` 标签不匹配，正常升级链零影响）；
- 研发界面新增 core 分支（仿 activity/star/grow 模式）：隐藏商店/兑换按钮、显示 **"通过开启核心获得"**、置位 `coreOnlyB`；
- 研发按钮启停条件追加 `(!coreOnlyB || modCraftFree)`；`upgradeClick` 入口对 `coreOnlyB && !modCraftFree` 硬拦截——覆盖研发升级卡旁路；
- **`modCraftFree` 保留豁免**：与修改器"一切交互无视一切条件"既定语义一致；
- 数据层 `price/Jprice` 残留不动：UI 封死后不可达；且全量 grep 证实 `cutter_gold` 仅存在于武器定义 xmlClass7、未进任何商店/兑换清单 bin，`Jprice=48` 本无实际入口；
- **黄金恶魔牙线未动**：`goldflyBlade` 走 grow（成长计划）提示，其未拥有理论可 0 价研发属同型既有缺口，本次按裁定不扩 scope，如需统一处理另行立项。
