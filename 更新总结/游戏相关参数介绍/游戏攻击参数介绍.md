# 游戏攻击参数介绍（伤害公式与参数手册）

> 建册日期：2026-09-17
> 依据：GitHub 版反编译源码逐行核验（锚点随文标注），并用实机面板数据交叉验证（黄金黑绳 160 级面板：公式计算 13966 / 面板 13965，逐位吻合）。
> 定位：**当前版本（3.0 前瞻）攻击数值的现行机制说明**——后续调数值前先读本文，避免按旧认识（如"改配置 hurt=改伤害"）动手。
> 范围声明：本文覆盖 `bullet`/`missile` 类物理弹的完整公式；`laser`、`lightning` 类有独立分支（文内标注处只给入口，未展开）。"战斗力"总公式未深挖，不在本文范围。

## 一、总公式链（从等级到面板单发伤害）

```text
① 有效武器等级 commonLevel
     = max(配置 commonLevel, 人物等级 + 原生成长 + 1)        ← 仅 Level_Growth 成长型武器
     = 配置 commonLevel                                       ← 非成长型武器（固定）

② 基础DPS baseDps = 10 × 有效等级^1.5 + 2                    ← getDpsByLevel，全武器同一条曲线

③ 职业乘数（写死的类常数）
     主武器(arms) × 4 × 1.2 = ×4.8
     副武器(sub)  × 1.15 × 1.2 = ×1.38

④ 实时DPS = 基础DPS + 芯片附加 dpsHurt                        ← getDps()；芯片/词条从这里进

⑤ 单发伤害 = 实时DPS × (attackGap + 0.1) ÷ (shootNum × bulletNum) × reduceRa
                                                          ← getHurtByDps × reduceRa
```

（OneArmsDefine.fleshData / getHurtByDps：`OneArmsDefine.as:399-420、508-524`；getDpsByLevel：`GameDefine.as:379-382`）

**验证实例**：黄金黑绳，人物 149 级（有效等级 = 149+10+1 = 160）：
基础DPS = 10×160^1.5+2 = 20241 → ×1.38 = **27932**（面板"基础战斗力 27931"）→ ×(0.9+0.1)×0.5 = **13966**（面板"武器伤害 13965"）。

## 二、核心结论（设计口径）

1. **伤害由等级-DPS 曲线反推，不读配置 hurt**——`get hurt()` 对 arms/sub 直接返回计算值，配置 `<hurt>` 字段是死字段（改它不改变游戏伤害）。全武器共用同一条 `10×L^1.5+2` 曲线：**等级足够时，同职业、同折算率的武器 DPS 一致**。
2. **单发与射速只是同一份 DPS 的分配方式**：attackGap 越小单发越低、打得越快，总量不变；多枪（bulletNum/shootNum）把一轮预算平分给每发。
3. **想突破"单发锁死"，只能靠多倍判定**：穿透（一颗弹穿多敌，每个都全额结算）、转移/弹射类、跟踪（保证命中率）——这是武器间实际输出差异的真正来源。
4. 职业差是硬性的：主武器类乘数 4.8 是副武器 1.38 的 **3.48 倍**——同等级下主炮单发天然是副炮的三倍半，副武器的价值在功能（跟踪/穿透/控制）而非站桩输出。

## 三、参数逐条介绍（配置字段 → 代码含义）

### 3.1 伤害换算类

| 参数 | 中文含义 | 代码行为 | 缺省 |
|---|---|---|---|
| `reduceRa` | **伤害折算率**（DPS→单发的"汇率"） | 直接乘进单发伤害（`OneArmsDefine.as:420/435/440/445` 四处，全库仅此四个消费点；Go 服务端不消费）。全武器分布 0.4~1.0 七八档：0.4=风剑/粒子刃/龙吟/杀猪刀；0.5=切割炮/热线/石龙人；0.7=战吼/挑战者/恶魔牙/黄金飞刃炮/黯灭/灰狐/**黄金深渊**（20260917 起）；0.8~1.0=银蛇/鞭炮/响尾蛇/星爆等；不写=1 全额 | 1 |
| `hurt` | 配置伤害（历史字段） | **对 arms/sub 是死字段**，运行时伤害全部由①~⑤计算；仅非 arms/sub 子体系读 hurtArr | — |
| `commonLevel` | 普遍等级 | 非成长型＝固定有效等级（也是成长型的**有效等级下限**）；影响面板与 DPS 起点 | 必备 |

> ⚠️ 常见误认：①`hurt` 不是实际伤害；②`reduceRa` 与减速无关（全库无减速机制，纯伤害乘数）；③"特殊属性"文字不携带数值（见 3.4）。

### 3.2 射速与弹数类

| 参数 | 中文含义 | 代码行为 |
|---|---|---|
| `attackGap` | **攻击间隔**（秒） | 开火循环周期（`ArmsAttack.as:326`，计时器逐帧累加至 ≥attackGap 出一轮）；换算公式里的 `(attackGap+0.1)` 的 0.1 是写死的引擎节奏补贴（帧取整开销），对所有武器统一，相对上利好快武器（0.4 间隔 +25%、0.9 间隔 +11%、1.4 间隔 +7%） |
| `attackDelay` | 攻击前延迟（秒） | 开火前的抬手时间；必须 < attackGap，否则按 attackGap 处理 |
| `bulletNum` | 一轮弹数 | 一轮射出的子弹数；换算公式除数——双发=每发预算减半、总输出不变（"DPS 锁死"的代码落点） |
| `shootNum` | 射击位数 | 同上，参与除数与射速显示；配置不写视为 1 |
| `bulletTranslation` | 双发错位距离（twips） | bulletNum≥2 时两发弹的上下错位量；不写=0（两发同点重叠，视觉一发） |
| `angleRange` | 散布角（度） | 单发时随机 ±散布/2 |

面板"攻击速度（发/秒）"＝ `1/(attackGap+0.067) × shootNum × bulletNum`（+0.067 同为引擎节奏常数，与 +0.1 不是同一个）。

### 3.3 等级与成长类

| 参数 | 中文含义 | 代码行为 |
|---|---|---|
| `specialType` | 运行时机制标识 | `Level_Growth_N`＝成长档 N：有效等级=人物等级+N+1（`OneArmsDefine.as:395-402`；id 以 "con" 开头的武器再叠加强化等级）；另有 `Chipped_Baby`、`Knowing_LightingBall`、`Skill_Laser` 等机制标识（各走专属分支） |
| `addArr` | 自带附魔（如 subAdd 控制训练） | 成长型武器可携带的词条入口（黄金深渊现无） |
| 紫色芯片成长 | 芯片提供的额外成长等级 | 与原生成长叠加；芯片路径的有效等级封顶 230（`ArmsItemsData.getPurpleGrowthCalculatedLevel`） |
| 人物等级 | 成长型的伤害引擎 | 成长型武器每点人物等级都推高有效等级 → DPS 按 `L^1.5` 增长 |

### 3.4 弹道与判定类

| 参数 | 中文含义 | 代码行为 |
|---|---|---|
| `specialProperty` | 特殊属性（**纯描述文本**） | "跟踪，穿透，成长型"等仅作展示；真实机制由 followB/penetrationB/specialType 各自承担 |
| `followB` | 跟踪敏捷度 | 0=不跟踪；标准 1；切割炮系=2（高敏捷跟踪）。跟踪不改变单发伤害，决定命中率与多目标接敌频率 |
| `penetrationB` | 穿透开关 | 1=可穿透敌人继续飞行，**每个被穿敌人全额结算一次 hurt（多倍判定的来源之一）**；0=命中即消失 |
| `beatBack` | 击退值 | 命中击退距离 |
| `backTime` | 回旋归来时间 | 0=不回旋 |
| `bulletSpeed` | 子弹飞行速度 | **只影响弹体飞行快慢，不进伤害公式**（docs/baselines 弹速清单管的就是它，防移植漂移） |
| `bulletLife` | 子弹寿命（秒） | 存活时间，默认 2；lightning 类公式分母用到 |
| `bulletWidth` | 子弹碰撞盒宽度 | **只作命中判定宽度，不影响视觉大小**（视觉=贴图本身，见 E2/R9 教训） |
| `bulletType` | 子弹类型 | `bullet`/`missile`=物理弹（本文公式）；`laser`=激光体；转移类（如鞭炮 type=转移炮）靠弹体跳转造成多目标判定 |
| `imgLabel` / `bulletImgLabel` / `hitImgLabel` | 武器/子弹/受击图像 | 本体加载走 imgLabel 原文（`ArmsDefine.armsImgLabel`），**不经过** `id_lvN` 动态拼接（getLabel 仅用于物品/存档字符串） |
| `smokeImgLabel` | 弹道烟迹图像 | 可空 |

### 3.5 经济与获取类（不影响伤害）

`energyUse` 能量消耗、`recoilValue` 后坐力、`mustLevel` 合成所需人物等级（成长型惯例=1）、`mustItems` 合成材料组（恶魔牙格式=`superalloy_numN,superalloy_Z_numN,...`；旧格式 `2,40,20`=标签集，经 `getArmsMustItems` 转换）、`price`/`priceLevel`/`Jprice`/`Mprice` 价格与销售档、`lightning`（>0 时伤害走 lightning 分支并附带落雷）。

### 3.6 加成入口（本文只记入口，未展开）

- 芯片直伤：`itemsData.dpsHurt` 加在 getDps()（④处）；
- 暴击与全局加成：`getAllDps() = getDps() × (1+暴击) × getAllArmsAdd()/getAllSubAdd()`（`OneArmsDefine.as:470-478`）；
- 追踪+穿透的多倍判定发生在命中结算层（`EventGroup.hurt`），不在公式链内。

## 四、速算例（黄金深渊五级，reduceRa=0.7（20260917 定稿），attackGap=0.9，单发）

单发伤害 = (10×L^1.5+2) × 1.38 × 1.0 × 0.7，L = 人物等级 + 成长(10/20/30/40/50) + 1

| 人物等级 | lv1 黑绳(L=+11) | lv3 焦热(L=+31) | lv5 深渊(L=+51) |
|---|---|---|---|
| 60 | 5781 (L=71) | 8388 (L=91) | 11299 (L=111) |
| 100 | 11299 (L=111) | 14486 (L=131) | 17926 (L=151) |
| 150 | 19736 (L=161) | 23525 (L=181) | 27530 (L=201) |

（历史备注：第一节验证例的面板截图摄于 reduceRa=0.5 时点，故为 13965；0.7 后同面板约 19551。20260917 早期速算表曾按 0.5 手算，本表已机算修正。）
