# 错误收集 · 目录说明

> 建立日期：2026-09-11
> 定位：集中归档**执行任务过程中实际遇到的错误、异常与陷阱**——工具用法、解析实现、部署构建、环境行为等，与具体武器家族无关的通用问题也放这里。
> 与其他目录的分工：家族相关的合并语义陷阱仍留在《武器家族内容\通用\》各总结内；本目录只做**错误本身的收集与复现要点**。每条错误必须备注**出现场景**（在做什么任务、哪一步、什么环境下发生）。

## 收录规则

1. 一类错误一个条目，命名 `主题-YYYYMMDD.md`（日期=首次收录日）；同类新例追加进已有文件，不另开新档。
2. 每条必须写：**现象 → 根因 → 正确做法 → 出现场景**（场景格式：`任务名·步骤·环境`）。
3. 已有解法验证过一次即可收录；"疑似"的先放条目末尾标注待复现。
