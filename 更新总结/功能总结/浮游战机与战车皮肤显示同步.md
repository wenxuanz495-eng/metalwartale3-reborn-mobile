# 浮游战机与战车皮肤显示同步

## 实现状态

已完成并通过实际游戏验证。

## 功能内容

本次实现了两条外观显示同步路径：

1. 主界面使用纯展示型 `CarImage` 容器，按战斗模式的车体资源装配规则显示当前战车和激活皮肤。
2. 背包装备栏仅对当前装备车辆进行皮肤显示拦截；名称、等级和属性仍来自原装备车辆数据，外观改为当前激活皮肤。

## 主界面调用链

```text
HighPlayerBox.flesh_byGameData()
  -> GameData.getHighDps_ExtraData()
  -> HighPlayerBox.showCar()
  -> 创建 CarImage
  -> 注册 Game.defineGroup.carImgLabelArr
  -> CarImage.showMC(基础车体)
  -> CarImage.showMC(激活皮肤)
```

主界面没有创建完整 `HeroCarBody`，也没有加载输入、AI、攻击、碰撞、生命值或关卡逻辑，因此只是不可操控的外观展示对象。

## 背包装备栏调用链

```text
_BagUI / _ChangeUI
  -> ChangeIconBox
  -> NormalAllIcon.inData_byItemsData()
  -> 检测当前装备车辆
  -> carItems.getActiveSkin()
  -> 加载激活皮肤的 `_items` 图标
```

只有同时满足以下条件才会拦截：

- 数据对象是 `CarItemsData`；
- 对象不是皮肤卡片；
- 对象是 `Game.gameData.carItems.equArr[0]` 当前装备车辆；
- 存在有效激活皮肤。

其他普通车辆和皮肤卡片仍使用原本的 `imgLabel` 图标路径。

## 数据与资源区别

- `activeSkinId`：皮肤背包对象 ID。
- `CarItemsData.getDefine()`：取得皮肤对应的 `CarDefine`。
- `CarDefine.imgLabel`：战斗车体和主界面 `CarImage.showMC()` 使用的外观标签。
- `CarDefine.getImgLabel()`：在 `imgLabel` 后追加 `_items`，得到皮肤背包图标标签。
- `CarItemsData.imgLabel`：普通背包图标使用的图像标签。

不能把 `activeSkinId` 直接当作 `getResource()` 的资源名；背包显示使用 `CarItemsData.imgLabel`，战斗/主界面展示才使用 `CarDefine.imgLabel`。

## 车库炮架显示 Bug 修复

### 问题现象

车库未装备皮肤时只显示车辆图标；装备皮肤后出现战斗用炮架。炮架并非皮肤图标的一部分，而是完整战斗车体资源中的组件。

### 原因

此前 `NormalAllIcon.inData_byItemsData()` 的皮肤拦截分支创建完整 `CarImage`，注册 `Game.defineGroup.carImgLabelArr` 的全部战斗车体，再通过 `showMC(activeSkin.getDefine().imgLabel)` 显示皮肤。该路径会带入战斗车体的炮架，因此车库图标出现了不应显示的组件。

`armsPoint` 只是挂点标记，`getSingleMovieclip(..., true)` 已将其隐藏；它不是炮架本体，所以移除 `armsPoint` 不能解决问题。

### 修复方式

车库当前装备车辆且存在激活皮肤时，改为直接加载：

```text
Game.swfLoaderManager.getResource("", activeSkin.imgLabel)
```

这里的 `activeSkin.imgLabel` 来自 `CarItemsData.fleshByDefine()`，而 `CarDefine.getImgLabel()` 会返回 `father + "/" + imgLabel + "_items"`。该资源是皮肤专用背包图标，不包含完整战斗车体炮架。

当皮肤 `_items` 资源不存在时，代码回退到原装备车辆的 `id0.imgLabel`，避免空资源导致图标异常。车辆名称、等级、防御类型等信息仍使用原装备车辆 `id0`。

### 影响范围

- 仅修改 `decompiled/gamefile/scripts/UI/_new/icon/NormalAllIcon.as` 的当前装备车辆皮肤分支。
- 主界面 `HighPlayerBox` 的半战斗皮肤展示保持不变。
- 战斗场景的完整车体、炮架、武器挂点和战斗逻辑保持不变。
- 普通车辆图标、皮肤卡片图标和车辆属性显示保持原路径。
