# 装包脚本"普通+迷你"双包改造 · 总结

> 记录日期：2026-09-19
> 分类：底层系统维护（发布装包工具链）
> 关联：`构建链去硬编码与遗留脚本归档-20260919.md`（同日去硬编码改造的后续）

## 一、目标

配合 3.0"抢劫版"Alpha 发行：版本名原样使用（不再强制拼接"内测版"后缀）；产出一套**完整包 + 迷你包**（迷你包排除开发者推荐曲库）；静音版流程停用（模板已冷备，本次不做）。

## 二、实际修改

`scripts\build_player_packages.bat` 重写：

1. **版本名**：`%VERSION%` 原样作为包名（调用示例：`build_player_packages.bat 3.0抢劫内测版Alpha`），产出 `<版本名>\` 与 `<版本名>.mini\` 两套目录及对应 `.7z`；
2. **迷你包**：与完整包同源同流程生成后，移除包内 `build\bgm\recommended\`（开发者推荐曲库，约 289MB）；保留 `build\bgm\default\`（原版默认 BGM 兜底）与 `build\bgm\player` + `tools\audio`（外置播放器与玩家曲库功能不受影响）；
3. **静音版流程移除**：`SILENT*`、静音模板校验、`build_silent_preview.bat` 调用与相关报错标签全部删除（脚本逻辑减半；历史版本可回溯 git 历史与 F 盘冷备 `静音版本归档\`）；
4. `:make_package` 去掉第二参数（静音版专用资源源），其余装包内容（播放器哈希校验、公告复制、根入口清单、`.release-ready` 标记）不变。

## 三、构建与验证（3.0抢劫内测版Alpha 实包）

- `构建.bat` 全量链随装包自动执行，退出码 0；
- 完整包：424MB（7z 压缩后 409,205,651 字节）；迷你包：136MB（7z 后 111,473,873 字节）；
- 两包 `build\game.swf` SHA-256 均 = `3C96640B…`，与主仓构建产物一致；
- 完整包含 `build\bgm\recommended\`，迷你包不含，`default`/`player` 两包齐全；
- 包内 `build\公告.txt` 首行 = 【3.0"抢劫版"Alpha 更新公告】（随包自动从 `runtime\公告.txt` 刷新）；
- 根入口（启动游戏-flashplayer_sa.bat、打开公告.bat、发布装包规范.txt 等）与 `tools\runtime\FlashPlayer.exe`（固定哈希校验通过）齐全。

## 四、遗留与待办

1. 包产物（两目录 + 两 7z）位于工作区根，分发后按冷链规则归档（建议 F 盘 `2.0版本归档\` 同级新开 3.0 归档或按用户裁定）；
2. 静音版如需恢复，从 git 历史取回本文件上一版并恢复 F 盘模板临时拷回流程；
3. 发行后可在装包提交上补 git tag（如 `v3.0.0-alpha`），版本年表接续 v2.4.2。
