# 开发商维护 · 分类索引

> 定位：收录**非游戏内容**的底层系统维护——本地服务端（`server\`）、启动器、客户端引擎层基础设施（日志/上报/加载/渲染管线）、构建与发布工具链等。这类改动不改变玩法、数值与美术内容，维护的是"游戏能被开发、被诊断、被长期运行"的地基，类比商业游戏的开发商补丁/引擎更新。

## 与其他分类的边界

- 玩法规则与架构：`docs\`（长期行为文档）
- 武器家族相关：`武器家族内容\`（含 `相关bug修复\`）
- 版本批量的系统级改动（界面、存档、商城等玩家可见功能）：`版本更新总结\`
- 执行中踩到的错误/陷阱（通用工具链问题）：`错误收集\`
- **本分类**：服务端/启动器/引擎基础设施本身的修复与维护（如日志通道、上报管线、进程管理）

## 命名与格式

同总索引规则：`主题-YYYYMMDD.md`；总结必备四段（目标、实际修改、构建与验证、遗留与待办）。
