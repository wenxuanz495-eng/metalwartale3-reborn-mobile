【2.2.5 内测版更新公告】

2.2.5 更新内容：
1. “领取星座武器”入口改为永久显示。无论12件星座武器是否领取完毕，玩家都可以继续打开领取界面查看状态；已经领取的武器仍保持灰显且不能重复领取，未达到20级时仍会提示等级要求。
2. 重做离线单人公会建筑贡献。科技院以及射击、体能、防御、控制四项训练，每次贡献由增加1点经验调整为增加50点经验，用于还原原版最高50人公会的共同建设效率。
3. 取消离线公会建筑每日1次普通贡献和2次额外贡献的限制。玩家只要拥有足够材料即可连续贡献，不再依赖每日登录和签到式等待；单次材料消耗、科技院等级门槛及训练解锁关系保持不变。
4. 科技院或训练项目达到最高等级后，贡献按钮会自动禁用，避免继续点击造成材料误扣。

2.1.6 追加维护：
1. 恢复并扩展芯片处理中心。材料背包的一键出售入口现在会打开独立的大型界面，可按品质和等级范围清理芯片，并可分别设置绿色、蓝色、金色、橙色芯片的自动出售规则。自动规则默认关闭，支持扫描并确认出售背包中已有的符合条件芯片。
2. 车身背包新增独立的“战车处理中心”。支持对白色、蓝色、金色、橙色、绿色战车按品质一键出售，并可为五种品质分别开启新获得战车自动出售。手动批量出售会显示数量和预计 G 币并二次确认；车皮及已装备战车不会被自动出售。
3. 修复暂称“印钞机”的物品复制漏洞。此前开启免费制造后，将晶体或芯片从背包拖入镶嵌槽、洗炼槽时，原物品可能未从背包删除；再次拖回背包便会生成重复物品。现在制造费用豁免与物品位置转移已经分离：进入槽位必须真实移除背包原件，取回时只在成功写回背包后清空槽位，替换失败会回滚，不再复制芯片或晶体。
4. 背包已满时，从洗炼槽取回芯片会保留槽内芯片并提示空间不足，不再出现槽位清空、物品丢失或重复生成。

2.1.5 追加维护：
1. 修复精英副本免费扫荡不显示、反而进入关卡备份提示的问题。普通精英副本只要已经通关且免费次数尚未使用，即可弹出扫荡确认，不再额外要求玩家等级高于副本10级。
2. 修复选择“播放开发者推荐 BGM”时仍可能读取玩家自定义歌单的问题。开发者模式现在固定使用开发者主界面与战斗歌单，和玩家自定义歌单彻底分流。
3. 普通关卡胜利结算页新增“进入下一关”。按钮仅在确实存在下一关时显示，失败、教程关、最后一关、精英副本、特殊副本、竞技场和公会战不会显示；进入下一关仍经过存档保护与关卡资源验证。
4. 修复初版“进入下一关”按钮与原版 Flash 时间轴 UI 不兼容、导致游戏停留在原版标题加载界面的问题。最终按钮改由安全的外层 UI 动态挂载，并已通过实际启动日志验证。

此前累计维护：
1. 为玩家自定义歌单增加独立的“播放玩家自定义歌单 BGM”开关。玩家歌单不再依赖双击歌曲临时播放；勾选后会自动启动当前场景绑定的玩家歌单，并在主界面与战斗切换时继续使用对应歌单。该模式与原版默认 BGM、开发者推荐 BGM 互斥，设置会自动保存。
2. 修正玩家自定义歌单在进出关卡时中断的问题。主界面与战斗即使绑定不同歌单，只要当前歌曲仍然存在于目标场景歌单中，就会保持原播放位置继续播放；只有当前歌曲不属于目标歌单时才切换。玩家在设置中主动切换歌单或双击歌曲时仍会立即换曲。开发者歌单与玩家曲库歌曲均适用。
3. 修正单曲循环的时间轴显示，歌曲进入下一轮循环时进度条会回到开头并继续前进。
4. 修正战车背包“更多操作”菜单容易被相邻战车透明区域关闭的问题，并增加点击菜单外空白处关闭功能。
5. 修正第八章第1关“卡斯堡垒”快速击杀敌人后，死亡动画残留对象可能被误判为存活敌人并造成空气墙不解除的问题。
6. 增加芯片自动洗炼。玩家可以为未锁定属性填写目标区间，并逐项选择“达标即停”；任意勾选项目达到自己的目标即可停止。全部不勾选时，需要所有已填写目标同时达标。芯片移除、材料不足或玩家手动停止时也会安全结束并保存结果。
7. 存档修改器新增军衔与功勋编辑，可选择全部30级军衔并填写当前军衔功勋；修改时会同步实际军衔等级、显示名称与累计功勋，避免只改文字造成存档不一致。
8. 调整普通关卡的难度继承：通关高难度后，同一关卡的较低难度会同步通关并获得星星；首次通关奖励按照本次新增通关的难度数量汇总发放。低难度通关不会反向解锁高难度成绩。

一、声音设置与键盘映射
右上角设置入口新增独立的音效音量、BGM音量与BGM开关，并加入完整键盘映射。音效音量与BGM音量首次启动均默认为70%。设置会自动保存，进入关卡后也可以从左下角入口打开。

原版Flash音频结构较为混乱：部分声音由ActionScript代码播放，部分直接绑定在敌人、爆炸和地图动画时间轴中，同类声音也可能走不同路径。当前版本采用统一基础衰减与BGM独立补偿：
原版声音先经过约0.09的基础衰减，再由音效音量调节；独立BGM使用单独的BGM音量与补偿参数，不再让“主音量”名称误导玩家。
这种方式能够在不逐个重做敌人和地图资源的前提下降低刺耳音效，并让BGM保持合适响度。

此前审计涉及125个敌人资源，其中96个SWF直接触发死亡声音，共发现119个嵌入声音引用。若彻底重构，需要逐项拆分代码声音与动画时间轴声音，工程量和回归风险都很高，因此本版保留稳定的统一衰减方案。

二、开发者曲库与自定义歌单
新增独立BGM播放器。开发者推荐BGM与原版默认BGM互斥，可在设置中自由切换；主界面和战斗场景分别使用自己的歌单，地图切换时会自动使用对应场景歌单。

玩家可以：
1. 浏览开发者曲库和独立的玩家曲库。
2. 创建并重命名自定义歌单。
3. 将开发者歌曲与玩家歌曲混合加入同一歌单。
4. 指定某个歌单用于主界面或战斗，同一场景同时只会启用一个歌单。
5. 选择顺序、随机或单曲播放，并通过序号调整曲目顺序。
6. 双击立即播放，使用上一曲、暂停、下一曲和时间轴跳转。

玩家曲库支持MP3、FLAC、WAV。将歌曲放入玩家曲库后，点击“刷新曲库”即可显示；玩家导入的歌曲不会包含在官方安装包中。

三、关卡资源与启动稳定性
增加关卡资源实例化验证、加载重试与失败后原地重载。关键敌人SWF、贴图或动画未正确实例化时，不再直接进入残缺关卡，以减少怪物不行动、贴图消失和刷怪流程中断造成的空气墙。

本地服务改用高位随机端口，并增加实例校验，避免占用常用端口或误连到其他目录、旧版本残留的后台服务。

四、存档与备份保护
移除首页手动保存的60秒冷却。保存时可选择是否同时创建备份；进入关卡前默认提示是否备份，也可以在设置中关闭该提示。保存失败时会阻止进入关卡，备份保存在saves\backups并自动保留最近20份。

五、公会战、竞技场与战斗核心
提高公会战难度与收益，修复公会战Boss血量显示为NaN的问题。改良战斗核心的基础获取、固定奖励、随机奖励和彩蛋奖励，单开与批量开启使用相同结算规则。

公会战和竞技场翻牌中的斯巴达武器已替换为50 M币；普通超合金相关掉落已经提高，后续数值将根据玩家反馈继续观察。

六、其他修复
支持多个武器槽装备同一种主武器或副武器，每件武器仍保留独立等级、芯片、强化和附加属性。
修复公会战奖励进入背包后部分图标不刷新的问题。
移除芯片洗练成功后反复遮挡操作的提示框。
修正修改器生成紫色芯片时额外增加1级的问题，紫色芯片共鸣等级最高230级。
“奥”与“双刺战机”的等级及对应基础属性已经对调。

资源加载报错本身不会删除存档；如果安全软件阻止写入，请先关闭游戏并确认saves目录中的game_save.bin仍然存在，不要直接创建新存档覆盖。
